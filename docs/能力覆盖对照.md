# 能力、练习与最终复用对照

这里记录实际课程映射。数组短题练操作，后续层需自己写入这些操作，不自动调用短题的 solve。代码测评通过不等于学习者已验收动画。

## 成品的调用关系

个人英文训练程序将串起四条路径。语料路径调用 `tokenize` 和 `make_batch`。模型路径以 `GPT` 为入口，实际创建 `Embedding`、`Block` 和 `RMSNorm`。`Block` 再使用 `MultiHeadAttention`、`AttentionCore`、`MLPBranch` 和其子层。训练路径使用 `CrossEntropy`、全局梯度裁剪和 `AdamW`，计划从现有 `train` 提出一次更新供固定批次与最终程序共用。推理路径调用 `generate`、`sample` 和 `Softmax`，与训练共用 `GPT`。课程提供的检查点工具连接训练、恢复和生成。`Parameter`、`Module` 以及升级过的初始化接口由多条路径共享。

第一部分是模型理解，第二部分是操作准备。比如散射加对应 `Embedding` 的重复编号梯度，换轴对应多头注意力。去均值及其反向主要通向选修 `LayerNorm`。`Scale` 在独立练习和基础层测评中使用，当前个人 GPT 实例化的子层没有 `Scale`。三维 `Linear` 前向短题是完整 `Linear` 的过渡。旧训练单步与分项检查保留在回收站，由最终程序的实际训练、续训和生成承担交付验收。

已用当前本地模块跑过两步固定批次训练、生成和检查点读写，并核对 `GPT` 下的实际子层。这个验证覆盖现有组件。当前网页和 `run_gpt.py` 的控制循环仍由平台提供，个人入口的网页和命令行接入待实现。
