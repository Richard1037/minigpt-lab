# 初始化接口升级 · 2026-11-17

## 教学安排与原因

用户认可在第七部分增加衔接任务，避免回改旧课导致尚不知GPT时就出现复杂配置。现在顺序为：t_data→t_init_upgrade→t_gpt。原基础层的教学要求、接口默认行为与测评版本保留，只增加后续升级入口。新任务是一次完整能力升级，修改原模块构造器；不建立第二套计算模块，不拆成六道重复练习。

原设计为保留基础接口，在GPT创建所有子层后再重置权重，导致重复初始化、外层了解内部布局。此前按语义角色定位修复了命名误判，但未解决封装问题。此次改为：GPT提供同一生成器、标准差与出口系数，组合层向下传递，Linear/Embedding创建自己的参数。以后审查同时核对模块职责、配置传递、重复创建/初始化与个人成果复用。

## 增量接口

- Linear：保留C/D/use_bias，增加仅关键字rng=None/init_std=None/init_scale=1.0。标准差未指定沿用initialize(shape,rng)，指定时直接normal采样；只走一条初始化分支。
- Embedding：增加rng=None/init_std=0.02，无生成器保留旧种子零行为，有生成器使用同一对象。
- MLP/MLPBranch/MultiHeadAttention/Block：增加rng/init_std/init_scale可选关键字。Branch原eps位置参数保持。MLP仅fc2、注意力仅proj使用出口系数，Block传给两分支。
- Block先创建注意力再创建MLP分支，与前向主线及原随机流顺序一致。内部命名不强制；参考采用公开ffn，不要求旧norm2/mlp别名。
- GPT只创建一个生成器和出口系数，然后构造两张表、Block列表与最终Norm；删除matrices/exits/内部参数搜索和重新赋值。前后向算法保持。

随机顺序保持字符表→位置表→各层qkv/proj/fc1/fc2，二维参数各采样一次。Norm全一、偏置全零，两个出口乘1/√(2L)。原GPT全部8项期望与数值用例保持，另加一次初始化追踪项，总9项；接口要求变化升revision4，历史成绩保留。下游只补齐新先修的依赖闭包，正文、数值标准和版本不变。
