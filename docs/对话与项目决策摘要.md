# miniGPT Lab 对话与项目决策摘要

项目的目标是亲手用 NumPy 完成一个能训练、保存恢复并续写文本的小型 GPT。网站承载讲解、动手练习、测评和训练实验。个人实现、可折叠参考代码和网站调度各有明确入口。

## 教学与工程约定

- 讲解从整体目的和输入输出开始。新变量先交代来源，再串起完整前向，最后用核心公式或流程图收束。反向推导旁重列对应前向公式，统一用 ∇X 标识梯度。
- 练习按真实模块和新增能力组织。已写组件直接复用，编辑框保留，题末给出动手清单和关键公式。样例和参考代码默认折叠。
- 测评覆盖真实调用路径，按行为与数值验收。`Module.parameters()` 负责参数去重，训练和优化器直接使用其结果。讲解验收与代码成绩独立。
- 图示优先解释实际依赖和数据去向。相同批次或头的操作只示范一组，选择题独立呈现。正文内回看链接提供返回入口。

## 训练实验室

- 使用英文字符语料。语料和训练参数放在常驻可折叠侧栏，训练提交时保存本次配置。每次新实验自动抽取种子，历史回放沿用原种子。
- 一个模型可分别续写最多三条开头。每条结果有独立的逐字符播放和采样概率，词汇库可展开查看。
- 参数范围与接口一致。训练诊断按前向激活、裁剪前梯度和参数更新三步组织。自填语料默认用末尾 20% 验证，手填独立验证文本有单独的反馈。

## 当前交付与后续方向

- 用户于 2026-11-19 确认验收现有课程讲解。目录展示主线和训练实验室，通用数值拓展从顶部学习工具打开。
- 个人英文训练程序后续由学习者组装，网站调用同一个入口并呈现训练、续训与生成结果。完整参考程序独立展示。
- 英文短对话作为后续展示实验，计划用同一检查点比较不同上下文对回答的影响。个人程序接入和对话实验的进度以课程完善清单为准。
