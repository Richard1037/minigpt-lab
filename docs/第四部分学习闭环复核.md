## 建议的本部分收尾

将末节改为基础层综合组装与验收：学习者只写新的组合部分，已有层通过真实导入复用。

主组合可使用 GPT Block 中实际存在的 MLP 分支：先 RMSNorm，再 MLP。它由个人 RMSNorm、MLP、内部两个 Linear 与 GELU 构成，沿前向顺序调用、反向逆序传回梯度。它是完整 Block 的一条分支；本节不提前声称实现了注意力、整块残差或完整 GPT。组合必须解释输入、各中间量、输出、上游与各参数所属对象。

综合测评由两部分组成：

- 对上述真实分支检查完整非单位 batch/token、不同宽度、整体输入梯度、所有参数梯度、跨层缓存、累计与统一清零；检查实际子层实例来自个人实现，拒绝用另一份参考层代替。
- 对个人公共接口、初始化、Embedding 和 Scale 运行已有能力检查。Embedding 检查查表与重复编号梯度回行；Scale 作为必要的反向学习例题保留其原有用途。它们可以在独立路径中验收，不能为了全放进一张图而发明 GPT 中不存在的串联结构。上游梯度直接给定，此阶段不要求尚未学过的损失、优化器或训练循环。

增量修改必须保护已验收内容和个人成果：只补未交付的构造责任；旧重复题保留历史记录，新的综合接口与成绩单独区分。个人已经实现的方法不能重置。网页和本地调用同一份模块，后续各 Part 接收同一份代码。
