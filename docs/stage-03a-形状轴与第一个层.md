## 1. 这一步在干什么

把阶段 1–2 的标量引擎换成 numpy 整块数组。数学一模一样，**每个"数"变成"一摞数"**。
收益是快一万倍（一次 `@` 顶替几十万次 Python 调用），代价是反向传播你要自己写出

这一阶段**没有新数学**。真正难的是换一种推理方式：

* 标量阶段：靠**数字**推理（这个梯度是 36 还是 24？）
* 数组阶段：靠**形状**推理（要得到 `(out,in)` 的 `gW`，只能是 `gᵀ @ x`，没有第二种可能）

## 2. numpy 的三件事：形状、轴、`@` 收缩

后面所有推导都建立在这三件事上。这一节不写任何梯度，只把一个数组翻来覆去看懂：
`x = np.arange(24).reshape(2, 3, 4)` —— 就是 0 到 23 这 24 个数，按顺序填进
"2 块、每块 3 行、每行 4 个"的格子里。建议开着 python 跟着敲，10 分钟就够。

### 2.1 形状 = 取一个数要报的几个坐标

`x.shape == (2, 3, 4)` 的意思是：想指出 x 里的某一个数，你要报 3 个坐标
`x[i, j, k]` —— 第几块、第几行、第几个。三根轴在本手册里有固定名字：
`axis=0` 是"哪条序列"，`axis=1` 是"第几个 token"，`axis=2` 是"第几维特征"。

```example
x[0, 0, 0] = 0，x[0, 0, 1] = 1：最后一轴走得最快，同一行里挨着的就是"第几维"。
x[0, 1, 0] = 4：换一行跳 4 个，因为一行有 4 个数。
x[1, 0, 0] = 12：换一块跳 3×4 = 12 个，因为一块有 3 行 4 列。
所以 shape 的每个数告诉你"沿这根轴走一步跳多远"：轴 2 跳 1、轴 1 跳 4、轴 0 跳 12。
以后看到 `g2.sum(axis=0)`，别想公式，想"把'哪条序列'这根轴压没"。
```

### 2.2 `reshape(-1, C)`：把几块板子上下摞成一张大板子

矩阵乘只吃二维，所以 `(B, T, C)` 要先摞成 `(B·T, C)`
（`B` = 几条序列、`T` = 每条几个 token、`C` = 每个位置几维；§4 约定 1 会正式钉死）。
`-1` 的意思是"这一轴的长度你自己算"，一个式子里只能有一个 `-1`。

什么时候合法，一句话：**只把相邻的轴合并、不打乱元素顺序，就合法。**
想把不相邻的轴并到一起（比如 `(C, B·T)`）不是 reshape 能做的，得先 `transpose` 再 reshape。

```example
x.reshape(-1, 4) 的第 0 行 = 块 0 的第 0 行 = [0, 1, 2, 3]。
第 3 行 = 块 1 的第 0 行 = [12, 13, 14, 15]：前 3 行来自块 0，后 3 行来自块 1。
所以 reshape(-1, 4) 就是"把两块 3×4 的板子上下摞成 6×4"，每个数都没换位置。
```

还有一个和 `gradcheck` 直接相关的性质：`reshape` 在**连续内存**上返回视图
（和原数组共享同一块内存，改一个另一个跟着变），在 transpose 过的非连续内存上返回副本
（各是各的）。§5 第三条会用到这句话。

把 `(B,T,C)` 想成 **B 块 `T×C` 的板子**：矩阵乘只吃二维，而 `W` 对每块板子的每一行都是同一块，
所以"逐块乘完再摞起来"和"拼成一块 `B·T×C` 乘一次"逐位相同。下面这个动画就是那三步
（点任意一行看算式，第 ⑤ 步是 §2.2 说的"不合法切法"）：

### 2.3 `sum(axis=k)`：沿第 k 根轴把那一排数加起来，加完这根轴消失

```example
x.sum(axis=2)[0, 0] = 块 0 行 0 那 4 个数相加 = 0+1+2+3 = 6，结果形状 (2, 3)。
x.sum(axis=1)[0, 0] = 块 0 列 0 那 3 个数相加 = 0+4+8 = 12，结果形状 (2, 4)。
x.sum(axis=0)[0, 0] = 两块在同一位置相加 = 0+12 = 12，结果形状 (3, 4)。
记忆法：`axis=k` 就是"消失的那根轴"，结果形状 = 原形状删掉第 k 个数。
```

反向传播里大量的活就是"求和该对哪根轴求"，而答案完全由**目标形状**决定：
手里是 `(N, out)` 的 `g2`，想要 `(out,)` 的 `db`，只能让 `N` 消失 —— 所以是 `g2.sum(axis=0)`。
不用背，看一眼形状就知道。

顺带两个常配的手势：

```python
a.mean(axis=-1, keepdims=True)   # 求完均值把那根轴留成长度 1，形状 (2,3,1)
a[:, None]                        # 在轴 1 插一根长度为 1 的新轴 → (2,1,3,4)
```

`keepdims=True` 在阶段 3b 的 RMSNorm 里是必需的：广播对齐要求两边轴数对得上，
留一根长度 1 的轴才能和 `(B,T,C)` 逐元素相乘。

### 2.4 `@`：两根轴配对求和，然后双双消失

`A @ B` 的要求只有一个：**A 的最后一轴和 B 的倒数第二轴等长**；这两个长度配对求和后消失，
结果形状 = A 剩下的轴 + B 剩下的轴。

```example
A 是 (2,3)、B 是 (3,4)：(A @ B)[0,0] = A 第 0 行 · B 第 0 列 = a00*b00 + a01*b10 + a02*b20。
中间那个 3 配对加完就消失，结果形状 = (2,) + (4,) = (2,4)。
X 是 (2,3,4)、W 是 (4,5)：4 和 4 配对消失，结果 = (2,3) + (5,) = (2,3,5)。
后一种情况 numpy 的做法是：对每一块、每一行，都乘同一个 W。
```

看到 `(2,3,4) @ (4,5)` 里那个 `4` 对齐了吗 —— 所以 **Linear 的 forward 其实可以不摊平**，
`x @ W.T` 直接就能算 `(B,T,C) → (B,T,out)`。那我们为什么还摊平？两个原因：
① 反向算 `dW = g @ x` 时必须是二维，否则 `gᵀ @ x` 会变成上面这种逐位置乘法，
形状根本不对；② 摊平后正向反向用同一套二维推理，只学一种手感。

最后把这个盒子拿在手里转一转：下面是一个真 3D 的 `(B,T,C)` 格盒，拖它旋转、
用滑杆换 B/T/C，点"压扁"看 `sum(axis=k)` 怎么把一整片同色格子加成结果里的一格 ——

### 2.5 速查表：想合成什么形状，就谁转置

设摊平后 `x` 是 `(N, in)`、`W` 是 `(out, in)`、`g`（对输出的梯度）是 `(N, out)`：

| 想要 | 目标形状 | 唯一拼法 | 代码 |
|---|---|---|---|
| 输出 `y` | `(N, out)` | `(N,in)(in,out)` | `x @ W.T` |
| `dW` | `(out, in)`，和 `W` 同形 | `(out,N)(N,in)` | `g.T @ x` |
| `db` | `(out,)`，和 `b` 同形 | 让 `N` 消失 | `g.sum(axis=0)` |
| `dx` | `(N, in)`，和 `x` 同形 | `(N,out)(out,in)` | `g @ W` |

这张表是 §6 的全部内容，也是整个阶段 3 的核心。**它不是要背的** ——
每一行都是"目标形状只有一种拼法能拼出来"。下次遇到新层（3b 的 RMSNorm、3c 的
CrossEntropy、阶段 4 的注意力），你就用同样的方式问："结果要和谁同形？那谁能消失？"
先用一组真数字把四行全走一遍：

```example
取 $x=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}$（$(2,3)$），$W=\begin{bmatrix}1&0&0\\0&1&0\end{bmatrix}$（$(2,3)$），$g=\begin{bmatrix}1&1\\1&1\end{bmatrix}$（$(2,2)$）。
$y=xW^{\top}=\begin{bmatrix}1&2\\4&5\end{bmatrix}$，形状 $(2,2)=(N,\mathrm{out})$。
$dW=g^{\top}x=\begin{bmatrix}5&7&9\\5&7&9\end{bmatrix}$：$g^{\top}$ 两行都是 1，所以每行就是 $x$ 各列的和，形状 $(2,3)$ 和 $W$ 同形。
$db=\textstyle\sum_n g_{n,:}=[2,2]$（`g.sum(axis=0)`）：$N$ 消失，形状 $(2,)$ 和 $b$ 同形。
$dx=gW=\begin{bmatrix}1&1&0\\1&1&0\end{bmatrix}$，形状 $(2,3)$ 和 $x$ 同形。
```

### 2.6 标量→数组：反向传播到底怎么推（不需要矩阵微分）

阶段 1 你推的是"一个数对一个数"的导数。现在一个"数"变成一摞数，看上去要先学矩阵微分 ——
**不用**。矩阵微分那套（$\partial Y/\partial X$ 是一个四阶张量、还要小心谁是分子布局）
在这门课里一次都不需要。你需要的是下面三条机械规则，它们把"对一摞数求导"全部翻译成
你已经会的那件事：**对某个位置求导，别的数当常数**。

**规则一：只写一个位置的标量式子。**
比如 `Linear` 的第 $n$ 个样本、第 $o$ 个输出：

$$y_{no}=\sum_{k} x_{nk}\,W_{ok}+b_o$$

现在问题变回了阶段 1 的问题：**这一个输出，对其中一个数敏感吗？** 敏感多少？

$$\frac{\partial y_{no}}{\partial W_{ok}}=x_{nk},\qquad
  \frac{\partial y_{no}}{\partial b_{o'}}=[\,o'=o\,],\qquad
  \frac{\partial y_{no}}{\partial x_{nk'}}=W_{ok}[\,k'=k\,]$$

第三个式子里 $[\,o'=o\,]$ 读作"只有 $o'=o$ 时是 1，否则是 0"。这不是新东西 ——
它就是阶段 1 里 `__mul__` 那句"局部导数是另一个操作数的值"，只不过数组里还得先回答
"你问的是不是**同一个位置**"。

**规则二：谁被用过多次，多份贡献就加起来。**
$W_{ok}$ 这一个数被 $N$ 个样本的第 $o$ 路输出同时用着，所以要把 $N$ 份贡献合并，
每份 = 那一路输出的梯度 $\times$ 规则一算出的局部导数：

$$\frac{\partial L}{\partial W_{ok}}=\sum_{n} g_{no}\,x_{nk},\qquad g_{no}\equiv\frac{\partial L}{\partial y_{no}}$$

到这里**推导已经结束了**。它就是阶段 1 那句 `self.grad += out.grad * 局部导数`，
只是把"所有用到它的地方"显式写成了求和号。剩下的只是把这条逐元素式子"收回"成 numpy 写法。

**规则三：结果必须和它对应的量同形，靠 §2.3 / §2.4 收回去。**
"收回"只有两种动作，而且都是形状问题，不是数学问题：

| 逐元素式子里的样子 | 形状上的动作 | numpy |
|---|---|---|
| $\sum_{n} g_{no}x_{nk}$：对 $n$ 求和，剩下 $(o,k)$ 两根轴 | 让 $n$ 消失 → $(\mathrm{out},N)(N,\mathrm{in})$ | `g.T @ x` |
| $\sum_{n} g_{no}$：对 $n$ 求和，只剩一根 $o$ 轴 | 让 $n$ 消失、不合成新轴 | `g.sum(axis=0)` |
| $\sum_{o} g_{no}W_{ok}$：对 $o$ 求和，剩下 $(n,k)$ | 让 $o$ 消失 → $(N,\mathrm{out})(\mathrm{out},\mathrm{in})$ | `g @ W` |
| 没有任何求和，$g$ 和某个量逐位置相乘 | 一一对应，形状不变 | `g * something` |

读法：**先数"求和号下有哪几个下标"，再数"结果还剩哪几根轴"**。剩的轴必须正好等于目标
张量的轴（§2.5 那张表说的就是这件事），不等就转置或 `reshape` 让它等于。

**唯一真正的新东西：广播。**
标量时代不存在"一个数被复制去参与很多个输出"，数组里到处都是（`b`、`Scale` 的 `w`、
`RMSNorm` 的 `s`、以及任何"求均值"）。它和求和是一对反着走的操作：

| 正向 | 反向 | 为什么 |
|---|---|---|
| **广播**（`b` 被复制成 $N$ 行去相加） | **求和**（沿被复制的那个轴把贡献合并） | 那个数被用了 $N$ 次，规则二 |
| **求和 / 求均值**（$N$ 个位置合成一个数） | **广播**（每个位置都分到同一份，均值再除 $N$） | 每个位置都对那个数有贡献，且贡献相同 |

两边各用一组小数字走一遍（先自己算，再点下一行对答案）：

```example
先看广播这一半。正向 $y = x + b$：$x$ 是 $(2,3)$，而 $b$ 只有 3 个数，被复制成 2 行去相加。
所以 $b$ 的第 $j$ 个数同时出现在 $y_{0j}$ 和 $y_{1j}$ 里 —— 它被用了两次。
上游给来 $g$：第 0 行 $[1,2,3]$、第 1 行 $[4,5,6]$。问 $b_j$ 该收多少？先自己算。
答案：用了几次就收几份，$\partial L/\partial b_j = g_{0j} + g_{1j}$，于是 $db = [1+4,\ 2+5,\ 3+6] = [5,7,9]$。
形状 $(3,)$ 和 $b$ 同形。写成 numpy 就是 `g.sum(axis=0)`：正向被复制的那根轴，反向沿它求和。
再看均值这一半。正向 $m = \frac{1}{6}\sum_i y_i$：6 个数合成 1 个，上游只给来一个数 $g_m = \partial L/\partial m$。
每个 $y_i$ 都以同样的方式（乘 $\frac{1}{6}$）参与了 $m$，所以每人分回同一份：$\partial L/\partial y_i = g_m/6$，六格相同、形状和 $y$ 同形。
对号入座：`Linear` 的 `db = g.sum(axis=0)` 是第 4 行那条；`loss = sum/N` 的 `/N` 是第 7 行那条（均值比求和多除一个 $N$）。
```

这两条规则用眼睛看比用字读快：下面这张图把两半都做成真的在流的动画 ——

**为什么永远不用写雅可比。** 严格说 $\partial y/\partial x$ 是 $(N\cdot\mathrm{out})\times(N\cdot\mathrm{in})$：
阶段 5 那批（$B{=}4$、$\mathrm{ctx}{=}32$、$d{=}48$）一个 `Linear` 就是 $6144\times6144$，三千八百万格，
比整个模型都大。但反向算的从来不是它，而是**上游那一束梯度乘上它**（$g^{\top}J$，形状 $(N,\mathrm{in})$）——
一次矩阵乘法，那个大矩阵从未被造出来。`gradcheck` 同理：逐个元素扰动，比的也是这一侧的数（§5）。

**阶段 1 的每条法则，在数组世界对应什么**：

| 标量自动微分（阶段 1） | numpy 层（阶段 3） | 变了吗 |
|---|---|---|
| 一个节点一个 `.grad` | 一个张量一个 `.grad`，**和它对应的量同形** | 只是形状 |
| `self.grad += out.grad * 局部导数` | 逐元素乘，再按参数剩下的轴求和/收缩 | 只是形状 |
| 链式法则 | 完全一样：每层收到的 `g` 就是上游算好的 $\partial L/\partial(\text{本层输出})$ | 没新数学 |
| 逆拓扑序逐个节点摊梯度 | 完全一样，"节点"换成了"层" | 没新数学 |
| （不存在） | 广播的反向是求和 | **唯一的新东西** |

**推任何新层的三步清单**（3b、3c、阶段 4 每一层都这么走）：

1. 写出**一个位置**的标量输出式子，带下标，别的当常数；
2. 对它求导 → 得到"这一个输入/参数位置该收到多少"；
3. 问两个问题：这个量**被几个位置用过**（→ 沿哪些轴求和），剩下的轴**是不是正好等于目标形状**
   （不等就转置/`reshape`）。写完立刻交给 `gradcheck`（§5）判，别靠感觉。

顺手练一遍：`GELU` 是纯逐元素的，没有参数，输入输出同形。用上面三步推它的 `backward` ——
你会发现第 3 步的两个答案分别是"没有被多个位置用过"和"轴一根不多一根不少"，
所以它的 `backward` 只有一行 `return g * d(x)`，**完全不碰任何 `.grad`**。
这不是特例，是这套方法的必然结果；3b §3 会正式用到它。

同一套方法第一次真正吃力的地方是 3b 的 `RMSNorm`：那里分母也依赖 $x$，
所以规则一"别的数当常数"这一句必须分两步走（先固定分母求导，再补上分母被改动的那份）。
那是这套推法里唯一需要"多算一笔"的情形，3b §4 会带你把它算出来 —— 你现在先把
"逐元素写出来 → 数下标 → 收回形状"这个动作练熟。

**这条动线是怎么从上一行变到下一行的。** 下面这张总表给出每层的形状；整条动线其实只有四种动作：

1. **查表加一根轴** —— `Embedding` 把每个词号换成 $d$ 个浮点数：$(B,T)\to(B,T,d)$；
2. **线性层只换最后一轴** —— $\mathrm{in}\to\mathrm{out}$，前面的 $(B,T)$ 原样带着走：qkv（$d\to 3d$）、fc1（$d\to 4d$）、fc2（$4d\to d$）、head（$d\to V$）全是它；
3. **reshape/transpose 不搬数** —— 拆头 $d=H\times(d/H)$、合头、$H$ 与 $T$ 换位，只是重新划线、换顺序数；
4. **matmul 收缩内维** —— 配对的两根轴逐对相乘再求和、消失，其余轴都活着：$q\,k^{\top}$ 消掉 $d/H$，$\mathrm{attn}\,v$ 消掉键轴 $T$。

其余的层（`RMSNorm`、GELU、softmax、掩码、残差）形状一动不动。

## 3. TODO-5A：`Scale` —— 先跑绿一次

`src/minigpt/nn.py` 里新加了一个最小的层：

### 3.1 契约

| 方法 | 要交出什么 | 形状 |
|---|---|---|
| `forward(x)` | `y = w * x`，并把 `x` 存进 `self._x` | 和 `x` 同形 |
| `backward(g)` | ① `self.w.grad += Σ(g·x)` ② `return w * g` | ①标量 ②和 `x` 同形 |

这正是 §2.3 那条规律的极端情形：所有轴都压掉。

为什么 `dx = w·g` 不用求和？因为 `x` 和 `y` 同形，一一对应，没有东西需要合并。

## 4. 五条约定，以及承载它们的已给出代码

现在回头看这些规矩 —— 你在 §3 已经见过其中两条了（缓存的下划线、梯度的累加）。

1. **激活值形状一律 `(B, T, C)`**：B 条序列、每条 T 个 token、每个 C 维。
   所有层的 forward 都是 `(B,T,C) → (B,T,C)`（Linear 会改最后一维）。
2. **全部 `float64`、行主序、连续内存**。
   用 float64 是为了梯度校验可信：float32 的有限差分噪声约 1e-3 量级，会盖过真误差（存检查点时再降 float32）。
3. **`Parameter` 同时有 `.data` 和 `.grad`，形状相同**；梯度**累加**，清零由训练循环负责。
   §3 那条"backward 两次后梯度翻倍"的判据就是在钉这一条。
4. **`Module` 协议只有两个方法**：`forward(*inputs)` 返回输出并把反向要用的中间量存进
   `self._缓存`；`backward(grad_out)` 返回**对输入的梯度**（没有可导输入就返回 `None`），
   同时把参数梯度累加进 `p.grad`。
   只有这两条纪律，任何层都能被 `gradcheck` 自动验证 —— 这是整个协议存在的理由。
5. **层内不藏随机性**：`forward` 必须是 (参数, 输入) 的纯函数。
   dropout、随机裁剪都不许出现在这一层（本阶段 dropout=0，阶段 8 才会引入，
   而且引入时要能被"关掉"以便梯度校验）。

### 4.1 关于"缓存"的规矩

`backward` 需要的中间量必须在 `forward` 里存下来，命名统一用下划线前缀：
`self._x`、`self._x_flat`、`self._r`、`self._probs`、`self._ids`。
下划线开头是有功能的：`Module._collect()` 会**跳过**下划线属性，所以缓存不会被误当成子模块。

另一个隐含约定：**一次 forward 配一次 backward**。中间不能插入别的 forward，
否则缓存被覆盖，梯度会算到另一条数据上。这个 bug 在后面写梯度累积（gradient accumulation）时
一定会来找你，记住这个约定。

### 4.2 `Parameter`：三行实现里的三个决定

```python
__slots__ = ("data", "grad", "name", "wd_exempt")
self.data = np.ascontiguousarray(np.asarray(data, dtype=np.float64))
```

| 决定 | 理由 | 不这样会怎样 |
|---|---|---|
| `__slots__` | 写错属性名（`self.grads`）立刻 `AttributeError` | 拼错的名字静静挂在对象上，梯度永远为 0 |
| 强制 `float64` | 有限差分的噪声底约 $\mathrm{ulp}(L)/\epsilon$；float32 下这个噪声是 $10^{-3}$ 量级 | 噪声盖过真误差，判据不可信 |
| 强制 contiguous | `reshape(-1)` 只有在连续内存上才是**视图** | 非连续时返回副本，`gradcheck` 扰动写不进真内存 → **假通过** |
| `wd_exempt` | bias 和 norm 的缩放系数不是"权重矩阵" | AdamW 会把它们衰减到 0，模型变笨 |

`zero_grad()` 用 `self.grad[...] = 0.0` 而不是 `self.grad = np.zeros_like(...)`：
前者原地清零，后者换了个对象 —— 如果优化器已经攥着旧引用（阶段 5 的 Adam 动量表按
`id(p)` 建索引），换对象会让它更新到一块被丢弃的内存上。这种 bug 不会报错，只会让
训练"莫名其妙地慢"。

### 4.3 `Module`：只有两个方法的协议

`__call__` 转调 `forward`，所以你写 `layer(x)` 而不是 `layer.forward(x)`。
差别不是风格：以后加 dropout、加缓存、加梯度检查开关，都塞在 `__call__` 里，
`forward` 保持纯函数 —— 这正是约定 5（"forward 必须是参数与输入的纯函数"）能守住的原因。

`_collect()`（参数收集）有三个不显眼但关键的细节：

1. **跳过下划线开头的属性**。`self._x`、`self._probs`、`self._x_flat` 是反向用的缓存，
   不是子模块。没有这条规矩，缓存会被当成参数登记进检查点。
2. **按 `id()` 去重**。weight tying 时输出头"借用"词嵌入的同一个 Parameter 对象，
   登记两次会导致三个后果：优化器对它走两步（等效 lr 翻倍）、检查点存两份、
   判据"参数不重复登记"挂。
3. **靠 `vars(self)` 的插入顺序**生成名字（`tok.weight`、`blocks.0.attn.q.W`）。
   顺序稳定 ⇒ 检查点的 key 稳定 ⇒ 以后 C++ 侧能按同样的名字读走权重。

### 4.4 `Linear.__init__` 的 `std*sqrt(2/fan_in)`

做法：权重按 `W = rng.normal(0, std) * np.sqrt(2 / fan_in)`（`std=0.02`）初始化，给你的代码已经这样写了。
你自己写新层时，凡"若干个输入加权求和"出来的矩阵，都套同一个式子。
两个因子各管一件事（一个管与 fan-in 无关、一个管整体尺度小），别把它们合并成一个魔法数 ——
为什么正好是这个数，见 §11 进阶推导 A。

### 4.5 `init_resid_scale`：$1/\sqrt{2L}$ 的用法

做法：构造完模型后，把每层**残差出口**的两个矩阵 —— `attn.proj.W` 与 `mlp.fc2.W` —— 乘上 $1/\sqrt{2L}$。
给你的代码已经做了这件事（`GPT.__init__` 的最后一步调用 `init_resid_scale(self, cfg.n_layer)`）。

三个"不乘"：
* q/k/v/fc1 不乘 —— 它们在支路内部，缩放它们等于改变支路的表达能力；
* bias 不乘；
* norm 的 `w` 不乘 —— 后两个本来就不该被缩放。

判据 `GIV-3` 数的是出口矩阵的范数比值：$L=3$ 时正好 $\sqrt6=2.4495$，并且别的张量一位不动。
为什么恰好是 $1/\sqrt{2L}$，见 §11 进阶推导 B；能切换 pre/post-norm 两种假设的动画在
[阶段 5 §3.3](s05.html#sec-3)。

### 4.6 "一次 forward 配一次 backward"

缓存存在 `self._xxx` 上，所以中间插入第二次 forward 会把第一次的缓存覆盖掉，
于是 backward 算的是**另一条数据**的梯度 —— 形状全对、loss 照降，只有梯度是错的。
阶段 7 做梯度累积（micro-batch 攒一次更新）时必须严格交替：

```
for micro in micros:        # 正确：forward → backward → (backward 里累加参数梯度)
    loss = model.forward(mb); model.backward(...)
optimizer.step()            # 攒完再走一步
```

而不是"先把所有 forward 跑完、再统一 backward"。

下面这张时间线把三种排法（`fwd→bwd` / `fwd→fwd→bwd` / `fwd→bwd→bwd`）真算一遍，把每种排法解析梯度对数值梯度的最大相对误差摆出来 —— 只有严格交替的那一种是 1e-10 量级，另外两种错得毫不报错。

## 5. 你的测谎仪：`gradcheck`

`src/minigpt/gradcheck.py` 已经写好，值得花 10 分钟读一遍，因为它就是你判据的全部。

```python
ok, worst, detail = gradcheck(Linear(5, 3, rng=rng), [rng.standard_normal((2, 4, 5))])
```

它做的事：

1. 用给定输入跑一次 `module(*inputs)`，得到输出。
   * 输出是数组时，随机生成一个**余向量 cot**（constant of projection），
     把"输出 → 标量目标"固定成 $\sum \mathrm{out}\odot\mathrm{cot}$（代码里是 `sum(out * cot)`）。
     有了标量才有梯度可谈。
   * 输出本来就是标量（如 CrossEntropy），直接用。
2. 跑一次 `module.backward(...)`，记下每个参数的解析梯度、以及**对输入的**梯度。
3. 对每个张量**抽查最多 24 个元素**（`_MAX_ENTRIES_PER_TENSOR`），做中心差分

$$\frac{\partial f}{\partial p}\approx\frac{f(p+\epsilon)-f(p-\epsilon)}{2\epsilon}$$

   并和解析值比。
4. 判定：相对误差 ≤ `tol`，或绝对误差 ≤ `atol`。

三个必须知道的细节：

* **整数输入自动跳过**：token id 不可导，所以 `Embedding` 只查参数梯度。
  这不是"检查变少 = 放心"，`gradcheck` 在**一个量都没查**时会直接判失败
  （"这不是通过，是没测"）。
* **`eps` 和 `atol` 是配套的**：差分的绝对噪声约为 $\mathrm{ulp}(L)/\epsilon$。
  当某个梯度本身只有 $10^{-8}$（数组层里很常见，多个大数相减的抵消结果），
  相对误差看着像 $10^{-2}$ 其实是噪声底。阶段 4 起判据用 `eps=1e-5, atol=1e-9` 就是这个原因。
  反过来，把 `atol` 调到 `1e-3` 就是在自欺 —— 它能盖住真 bug。
* **输入必须是连续数组**：否则 `reshape(-1)` 返回副本，扰动写不进真内存，
  校验会**假通过**。`gradcheck` 里那句 `np.ascontiguousarray` 就是在防这个。

"噪声底"这三个字值得亲眼看一次：把 $\epsilon$ 从 $10^{-9}$ 扫到 $10^{-1}$，误差走出一条 U 形曲线 ——
左支是舍入噪声（$\propto 1/\epsilon$）、右支是截断误差（$\propto \epsilon^{2}$），谷底夹在中间。
下面这张图真算这条曲线，并把 `eps=1e-5/1e-6` 与 `atol=1e-9` 标在图上：

## 6. TODO-5 / TODO-6：`Linear` —— 本阶段最重要的一层

$$y = x\,W^{\top} + b,\qquad W \in \mathbb{R}^{\,\mathrm{out}\times\mathrm{in}},\quad
  b \in \mathbb{R}^{\,\mathrm{out}},\quad x \in \mathbb{R}^{B\times T\times \mathrm{in}}$$

### 6.1 forward 的四步

```
1) 记住：输入形状 self._in_shape、输出形状 self._out_shape（最后一维换成 out_f）
2) 摊平：flat = x.reshape(-1, in_f)      # B·T 个位置共用同一个 W，所以必须摊平成二维
3) 计算：y = flat @ W.T   (+ b)
4) 还原：return y.reshape(self._out_shape)
```

步骤 2 的依据就是 §2.2：`C` 是最后一轴，摊平不打乱它。
步骤 3 的依据是 §2.4：`(N,in) @ (in,out) → (N,out)`。

两个坑：
* 忘记 `W.T`：`(N,in) @ (out,in)` 形状直接不匹配，这是**会报错**的那种错，好事；
  真正危险的是 `W` 存成 `(in,out)` 的写法，形状全对但梯度永远错 —— 所以我们统一
  把 `W` 存成 `(out, in)`，让每一**行**对应一个输出神经元。
* 用 `x.shape` 当输出形状还原：`(B,T,C)` 变成 `(B,T,out_f)`，最后一维不同，
  必须自己构造 `_out_shape`。（我就踩过：`cannot reshape array of size 24 into shape (2,4,5)`。）

### 6.2 backward 的三件产出（用形状推，别背）

已知 $g \equiv \partial L/\partial y$（代码里的 `g`，形状和 forward 的输出一致），
三件产出按形状**唯一**确定 —— 每一行的推理都只有一条路：

| 要交出 | 形状推理 | 结果 |
|---|---|---|
| $\partial L/\partial W$ | 要和 $W$ 同形 $(\mathrm{out},\mathrm{in})$ → 只能是 $(\mathrm{out},N)(N,\mathrm{in})$ | `g2.T @ flat_x` |
| $\partial L/\partial b$ | 要和 $b$ 同形 $(\mathrm{out},)$ → 让 $N$ 消失（§2.3） | `g2.sum(axis=0)` |
| $\partial L/\partial x$（返回值） | 要和 $x$ 同形 $(\ldots,\mathrm{in})$ → $(N,\mathrm{out})(\mathrm{out},\mathrm{in})$ 再还原 | `(g2 @ W).reshape(_in_shape)` |

其中 `g2 = g.reshape(-1, out_f)`。

如果这张表还是太抽象，下一节用 12 个具体数字把它走一遍。

### 6.3 用具体数字走一遍（判据里就是这一组）

这是 `tests/test_layers_a.py` 第三组的例子，形状故意小到可以手算：
`B=1, T=2, in=2, out=3`。

$$\begin{aligned}
x&=\begin{bmatrix}1&2\\3&4\end{bmatrix}\in\mathbb{R}^{2\times 2}\quad(\text{拍平后 }N{=}2,\ \mathrm{in}{=}2),\\
W&=\begin{bmatrix}1&0.5\\-2&1\\0&3\end{bmatrix}\in\mathbb{R}^{3\times 2}\quad(\text{第 }o\text{ 行，}o=0,1,2),\\
b&=\begin{bmatrix}0.1&-0.2&0.3\end{bmatrix}\in\mathbb{R}^{3},\qquad
g=g_2=\begin{bmatrix}1&0&-1\\0.5&2&0\end{bmatrix}\in\mathbb{R}^{2\times 3}\quad(N{=}2,\ \mathrm{out}{=}3).
\end{aligned}$$

**正向**（`y = flat @ W.T + b`，`W.T` 的第 `o` 行就是 `W` 的第 `o` 列）：

$$\begin{aligned}
y_0&=[1,2]\,W^{\top}+b
=\bigl[1\cdot1+2\cdot0.5,\;1\cdot(-2)+2\cdot1,\;1\cdot0+2\cdot3\bigr]+b
=[2.1,\,-0.2,\,6.3],\\
y_1&=[3,4]\,W^{\top}+b
=\bigl[3+4\cdot0.5,\;-6+4,\;12\bigr]+b
=[5.1,\,-2.2,\,12.3].
\end{aligned}$$

**`dW[o,i] = Σ_n g[n,o] · x[n,i]`** —— 注意这个求和压掉的是 `n`（样本轴），
留下 `o` 和 `i`，所以结果和 `W` 同形 `(3,2)`。这就是 `g2.T @ flat`：

$$\begin{aligned}
dW_{0,:}&=1\cdot[1,2]+0.5\cdot[3,4]=[2.5,\,4.0]\quad(\text{g 的第 }0\text{ 列}=[1,0.5]),\\
dW_{1,:}&=0\cdot[1,2]+2\cdot[3,4]=[6.0,\,8.0],\\
dW_{2,:}&=(-1)\cdot[1,2]+0\cdot[3,4]=[-1.0,\,-2.0].
\end{aligned}$$

**`db[o] = Σ_n g[n,o]`** —— 同样压掉 `n`，但 `b` 只有一维，所以是 `g2.sum(axis=0)`：

$$db=\begin{bmatrix}1+0.5&0+2&-1+0\end{bmatrix}=\begin{bmatrix}1.5&2.0&-1.0\end{bmatrix}$$

**`dx[n,i] = Σ_o g[n,o] · W[o,i]`** —— 这次压掉的是 `o`（输出轴），留下 `n` 和 `i`，
所以结果和 `x` 同形。这就是 `g2 @ W`：

$$\begin{aligned}
dx_{0,:}&=1\cdot[1,0.5]+0\cdot[-2,1]+(-1)\cdot[0,3]=[1.0,\,-2.5],\\
dx_{1,:}&=0.5\cdot[1,0.5]+2\cdot[-2,1]+0\cdot[0,3]=[-3.5,\,2.25].
\end{aligned}$$

三个观察，每一个都是判据会盯着的：

1. `dW` 和 `db` 都压掉了 `n`，因为 `W`、`b` 被所有样本共用 —— **"谁被重复使用，梯度就往谁身上汇"**。
2. `dx` 压掉的是 `o`，因为 `x` 和 `y` 是一一对应的（§3.2 里 `Scale` 的 `dx` 甚至不求和，同一个道理）。
3. `db` 是 `dW` 的一个特例：如果把 `b` 看成"输入恒为 1 的那一列权重"，
   `g2.sum(axis=0)` 正是 `g2.T @ ones` —— 这不是巧合，是为什么 bias 不吃 weight decay 的伏笔。

判据会把你写的矩阵结果和上面这组按定义算出来的数逐元素比，误差要 ≤ 1e-12。

```python
    def forward(self, x):
        in_f = self.W.data.shape[1]
        self._in_shape = x.shape
        self._out_shape = x.shape[:-1] + (self.W.data.shape[0],)
        flat = x.reshape(-1, in_f)              # (B,T,C) → (B·T, C)
        self._x_flat = flat
        y = flat @ self.W.data.T                # W 是 (out,in)，所以右边转置
        if self.b is not None:
            y = y + self.b.data
        return y.reshape(self._out_shape)       # 只把最后一维换成 out_f

    def backward(self, g):
        g2 = g.reshape(-1, self.W.data.shape[0])
        self.W.grad += g2.T @ self._x_flat      # (out,N)@(N,in) → (out,in)，和 W 同形
        if self.b is not None:
            self.b.grad += g2.sum(axis=0)       # bias 被 N 个位置共用，梯度要求和
        return (g2 @ self.W.data).reshape(self._in_shape)
```

`+=` 不是 `=`：同一个 `Linear` 被调用多次时（阶段 4 里不会，但阶段 5 的检查点/多次
forward 会），梯度要累加。`_in_shape` 必须在 forward 里存好，否则 `(B,T,C)` 进去、
`(B·T,C)` 出来，反向还原不了原形状。

**三个高频错，全都"能跑、loss 也降"**：

1. `self.W.grad = ...`（覆盖）而不是 `+=`（累加）。累加是**约定 3**，
   也是梯度累积、weight tying 的前提。
2. `use_bias=False` 时忘了判空 → `AttributeError`（这个会报错，算好的）。
3. 返回值形状没还原 → 上一层收到的梯度形状不对。

## 11. 进阶推导（现在可以跳过）

正文只讲"怎么做"。这一节收着两处初始化常数"为什么是这个数"的方差推导 —— 它们不影响你写代码、
跑判据，等你想深究再回来。两处用的是同一套算术（阶段 2 §3.1）：若干个互相独立的数加权求和，
结果的方差 = 各项方差之和。

### A. `Linear` 初始化里 `std*sqrt(2/fan_in)` 的来历

$y=\sum_{i=1}^{\mathrm{fan\_in}} w_i x_i$，$w_i\sim N(0,\sigma^2)$、$x$ 单位方差，于是

$$\operatorname{Var}(y)=\mathrm{fan\_in}\cdot\sigma^{2}\cdot\frac{2}{\mathrm{fan\_in}}=2\,\mathrm{std}^{2}$$

* $\sqrt{2/\mathrm{fan\_in}}$ 管**与 fan-in 无关**：不管输入是 64 维还是 1024 维，输出方差都是 $2\,\mathrm{std}^2$，不随宽度漂；
* `std=0.02` 管**整体尺度小**（GPT-2 的做法）：初始输出接近 0，loss 起点正好落在 $\ln V$ 附近，一眼看出模型"还没开始学"。

两个因子各管一件事，所以代码写成两个数相乘，而不是合并成一个魔法常数。

### B. `init_resid_scale` 里 $1/\sqrt{2L}$ 的来历：pre-norm 下方差线性涨

残差把子层输出直接加回主干。本项目是 **pre-norm**：子层看到的是 `RMSNorm(x)`，
它的方差被归一化钉在常数 $c$ 上、与主干方差 $v$ 无关 —— 所以每加一层，主干加进来的是一个
**常数** $2c$（两路：注意力、FFN），$L$ 层之后

$$v_L\;\approx\;v_0+2cL\qquad(\text{线性，不是指数})$$

把出口投影乘 $1/\sqrt{2L}$，每层的贡献变成 $2c\cdot\frac{1}{2L}=\frac{c}{L}$，
于是 $v_L\approx v_0+c$ —— **与层数无关**。这就是那个常数的来历，不是抄来的规矩。

对照：如果是 post-norm（子层输出正比于主干），递推是 $v_L\approx v_0(1+2c)^L$，
指数起飞，$1/\sqrt{2L}$ 只能减慢而不能消除。[阶段 5 §3.3](s05.html#sec-3) 的动画能切换这两种假设当场对比，
判据 `GIV-3` 数的就是这个比值（$L=3$ 时正好 $\sqrt6=2.4495$）。
