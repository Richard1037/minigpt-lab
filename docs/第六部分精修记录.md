| 步骤 | 本次交付 | 复用与后续用途 |
|---|---|---|
| 缩放打分 | 理解提问行/索引行的匹配与特征归约 | 具名导出 `attention_scores`，核心实际调用 |

| AttentionCore | 亲自构造、完整前向、逆序回到三个输入 | 因果/非因果、不同 query/key 长度与内容宽度 |

## 展示的选择

- 注意力使用同一组完整双批次/双头/三 token 数据；四个切片全部保留。分数、掩码、概率、读取及三条回流按对象切换，主公式说明整个运算与归约轴；任意格子可核对相关行/列。数值显示可选，无自动播放、移动点或默认逐数推算。
- 因果掩码后的零路径不标成有效来源。比如某一内容行只接收允许读取它的 query 上游，不把未来阻断路径也点亮。
- 多头使用有身份的特征片段显示换轴/拼接，完整保留两个 batch、所有 token/head；另显示投影输出的三段与持久核心。
- 残差图显示两次前向分叉，选择其中一次即可看到直连/分支接收同一上游并合流。
- Dropout 展示同一掩码的前向保留/阻断与反向系数，明确是确定关系示例，不冒充 NumPy RNG 回放。
- LayerNorm 显示六行实际输入、各自均值、中心化向量、统一行内缩放后的向量；正负分色。没有把相同坐标公式重复成大表冒充过程。
