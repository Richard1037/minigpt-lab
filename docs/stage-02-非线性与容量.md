## 2. 必要理论

### 2.1 线性 ∘ 线性 = 线性

- 第一层：$z = W_1 x + b_1$
- 第二层：$y = W_2 z + b_2$
- 代进去：

$$y \;=\; W_2\bigl(W_1 x + b_1\bigr) + b_2 \;=\; \underbrace{(W_2 W_1)}_{\text{还是一个矩阵}}\;x \;+\; (W_2 b_1 + b_2)$$

所以多层线性叠起来**等价于一层**，参数再多也没用 ——所以多层线性叠起来**等价于一层**，参数再多也没用 ——
它只能画出直线（在这里是一条水平线附近的直线，sin 的波峰波谷一个都抓不住）。
加深层数不买新能力，**加非线性才买**。

### 2.2 激活函数是"能不能表达"的开关

`tanh` 夹在中间之后，网络变成

$$y = \sum_{j} W_{2j}\,\tanh\bigl(W_{1j} x + b_{1j}\bigr) + b_2$$

——
8 个 S 形的、可平移可缩放的小台阶拼起来，就能逼近任意连续曲线（这是通用近似定理的直觉版本）。
sin 的 12 个点用 8 个隐藏神经元足够。

transformer 里对应的位置是 FFN 中间的 GELU，以及注意力打分后的 softmax。
**如果哪天你的 transformer loss 卡住不动，第一反应不该是"再训久一点"，
而是"我的非线性是不是被我不小心拿掉了"。**

### 2.3 激活函数全家福

从这一节起，讲的是**已经写在你眼前的代码**。手册不能只给"你要写的东西"的契约，
却把"给你的东西"当黑盒 —— 那等于让你自己反推，反而更费时间。
`exp / relu / sigmoid` 是三个样例（和阶段 1 §3 里那条 `__add__` 一个地位：演示闭包规则），
`tanh` 才是要你写的（TODO-4，阶段 2）。但四个都得读懂，因为**后面每次 loss 卡住，
第一个被怀疑的就是它们**。

| 函数 | 定义 | 导数 | 值域 | 性格 | 本项目在哪儿用它 |
|---|---|---|---|---|---|
| exp | $e^{x}$ | $e^{x}$ | $(0,+\infty)$ | 求导还是自己；$x\gtrsim 709$ 溢出 | `__truediv__` 和 sigmoid 的零件；softmax 的心脏 |
| relu | $\max(0,x)$ | $\mathbf{1}[x>0]$ | $[0,+\infty)$ | 最便宜；负半轴梯度恒 0 | 教学对照（FFN 最终用 GELU） |
| sigmoid | $\sigma(x)=\dfrac{1}{1+e^{-x}}$ | $\sigma(x)\bigl(1-\sigma(x)\bigr)$ | $(0,1)$ | 像概率；饱和得早 | 二分类输出；注意力里被 softmax 取代 |
| tanh | $\tanh(x)=\dfrac{e^{x}-e^{-x}}{e^{x}+e^{-x}}=2\sigma(2x)-1$ | $1-\tanh^{2}(x)$ | $(-1,1)$ | 零中心；饱和比 sigmoid 轻 | **阶段 2 的主角**；GELU 里也用它 |
| GELU | $\frac{x}{2}\Bigl(1+\tanh\bigl(\sqrt{2/\pi}(x+0.044715x^{3})\bigr)\Bigr)$ | 见阶段 3 §7 | $(-0.17,+\infty)$ | relu 的平滑版 | 阶段 3 之后的 FFN |

表里两个恒等式值得你亲手验一次（它们是"这几个函数是一家人"的证据）：

$$\tanh(x)=2\sigma(2x)-1,\qquad \sigma'(x)=\sigma(x)\bigl(1-\sigma(x)\bigr)$$

### 2.4 三条必须有的直觉

**一、饱和 = 导数趋 0 = 学不动。**
$\sigma(8)=0.999665$，而 $\sigma'(8)=3.35\times10^{-4}$ —— 曲线已经躺平，梯度基本没了。
`tanh` 同样饱和但轻一些（$1-t^{2}$，$|t|\to1$ 才趋 0）。
以后 loss 卡住别只想着"再训久一点"，先看激活值是不是长期贴在两端。

**二、零中心（zero-centered）为什么重要。**
sigmoid 的输出恒正。如果一层的输入全是正数，那么 $\partial L/\partial W = g^{\top}x$ 的
每一项都同号 → 这一层所有权重的梯度同号 → 更新只能"一起增"或"一起减"，
走的是锯齿形路线，而不是直指最优点。tanh 输出可正可负，relu 至少能把一半梯度归零而不是
全同号。这是历史上大家离开 sigmoid 的原因（比"tanh 更像线性"这种说法实在得多）。

**三、导数用"函数值自己"表示。**
`sigmoid` 的反向写的是 `s * (1 - s)`，`tanh` 的是 `1 - t*t` —— 用的是正向已经算好的那个值，
不再求一次 exp。两个好处：省计算，而且**这正是"forward 缓存中间量"这个约定的最早形态**。
阶段 3 里你会把它写成 `self._probs`、`self._xh`，道理一模一样：
反向需要的东西，正向顺手存下来。

### 2.5 relu 在 0 处不可导，代码里怎么选

`mask = 1.0 if self.data > 0 else 0.0` —— 在 $x=0$ 这个点上取了导数 0。
严格说 $\max(0,x)$ 在 0 处不可导（左导数 0、右导数 1），任选 0 或 1 都合法，
**但整个项目必须一致**：否则有限差分梯度校验会在 $x=0$ 附近给出"对不上"的假警报
（差分的 $\epsilon$ 会把点推到左或右半边）。这也是为什么本项目用 GELU 而不是 relu：
GELU 处处可导，梯度校验干净。

顺带记住 relu 的著名失效模式 —— **死神经元**：一旦某个神经元的输入长期为负，
它的梯度恒 0，权重从此不再更新，这个单元就报废了。GELU / leaky relu 存在的一半理由在这里。

### 2.6 exp 的溢出，和"减最大值"这一招

$e^{709}=8.2\times10^{307}$ 已经贴着 float64 上限，$e^{710}$ 直接 `OverflowError`。
所以本项目**从不**直接对 logits 求 exp，而是先减每行最大值 $m$：

$$\mathrm{softmax}(z_i)=\frac{e^{z_i-m}}{\sum_j e^{z_j-m}},\qquad m=\max_j z_j$$

分子分母同乘 $e^{-m}$，值完全不变；但最大项变成 $e^{0}=1$，其余 $\le1$，不可能溢出。
这一招会在三处反复出现：阶段 3 的 `CrossEntropy`、阶段 4 的注意力打分、阶段 7 的采样。
判据"logits=900 不溢出"就是在查你有没有记住它。

### 2.7 为什么注意力用 softmax 而不是"几个 sigmoid"

softmax 强制 $\sum_j a_{ij}=1$：**在第 $i$ 个位置，看向各处的权重加起来必须是 1**。
sigmoid 每一列各自开关，和不为 1，于是 $\mathrm{out}_i=\sum_j a_{ij}v_j$ 的尺度会随
"有几个位置被打开了"漂移 —— 序列越长越明显。

这个"每行和守恒"不是抽象美德，它在反向里必须被尊重：
阶段 4 的 `softmax_backward` 里那个减掉的项 $\sum_j(\mathrm{gp}_j p_j)$，
就是守恒约束的数学后果；同一个性质还让 $b_k$ 的梯度恒等于 0（一个死参数）。
看到"某处要减一个均值/加数"，条件反射就该想到"这是守恒约束"。

### 2.10 怎么区分"容量不够"和"优化没调好"

看 loss 曲线的形状，这个技能以后每次训练都要用：

* **容量不够**：前几十步快速下降，然后**平在一个较高的值**，无论训多久都不动。
* **lr 太大**：曲线**震荡**，甚至发散（值越来越大 / 出现 nan）。
* **lr 太小**：几乎是一条直线，降得极慢 —— 再等 10 倍时间才看得出是不是容量问题。

阶段 1 的 lr 演示是第二种，本阶段的对照组是第一种。

### 2.11 学习率衰减：为什么固定 lr 到不了最低点

梯度下降在谷底附近的行为是"跨过谷底 → 梯度反向 → 再跨回来"。
只要 lr 不为 0，这个来回就停不下来，你看到的 loss 是**谷底附近的一个震荡带**，
而不是谷底本身。把 lr 随时间收小，就是"越走越慢，最后停在谷底"：

$$\mathrm{lr}_t = \frac{\mathrm{lr}}{1 + d\,\dfrac{t}{T}}

\qquad (d = \texttt{decay})$$

$d=3$ 时末端的 lr 正好是初值的 1/4。

脚本第 3 组用 `decay=3.0` 跑 6000 步；你可以把 decay 改成 0 再跑一次，
对比 `MLP loss 下降倍数`（要求 ≥80）会不会掉下来 —— 会掉。这个实验值得亲手做一次，
它比这段文字有用。阶段 7 的 warmup + cosine 是同一道理的放大版。

### 3.1 `__init__`：为什么要造这些参数，以及为什么正好是这个数

参数不是"先造好再说"，它们是**你想表示的那个函数**的直接翻译。先把式子写下来：

$$y(x) = b_2 + \sum_{j=1}^{n_{\text{hidden}}} W_{2j}\;\tanh\!\bigl(b_{1j} + W_{1j}\,x\bigr)$$

然后逐个问一句"**删了会怎样**"——这才是"为什么要它"的答案：

| 参数 | 个数 | 式子里它是哪一项 | 删了会怎样 |
|---|---|---|---|
| `W1[j][k]` | $n_{\text{hidden}}\times n_{in}$ | $\tanh$ 里 $x$ 的系数：第 $j$ 个神经元"以多大倍率看第 $k$ 个输入" | $z_j$ 与 $x$ 无关，整个网络输出一个常数 —— 连直线都画不出来 |
| `b1[j]` | $n_{\text{hidden}}$ | $\tanh$ 的**拐点位置**（$z_j=0$ 发生在 $x=-b_{1j}/W_{1j}$） | 六个 tanh 全被钉在 $x=0$ 处翻转，网络只能表达关于原点对称的形状，$y=3x+1$ 这种就学不动 |
| `W2[j]` | $n_{\text{hidden}}$ | 第 $j$ 个神经元对输出的**贡献**，正负都能调 | 没有求和，输出等于第一个神经元的 tanh，其它五个白造 |
| `b2` | 1 | 整体上下平移 | 截距只能靠隐藏层硬凑，而隐藏层的和本来就受 $\tanh\in(-1,1)$ 限制 |

所以总数是 $3\,n_{\text{hidden}} + n_{\text{hidden}}\,n_{in} + 1$：

* `n_hidden=6` → **19 个**；
* 判据里那句"梯度校验(25 参数 MLP)"用的是 `n_hidden=8` → **25 个**（$3\times8+8+1$）；
* 对照组 `n_hidden=1` 只有 **4 个**，正好退化成 $ax+b$ —— 这就是 §2.1"线性∘线性=线性"的实物证据，
  也是为什么它必须学不动：它的参数集里根本没有能弯的东西。

**为什么 `W1` 是二维、`W2` 是一维**：`W1[j]` 要接 $n_{in}$ 个输入，所以是"每行一个神经元"的矩阵；
本阶段 $n_{in}=1$，每行只有一个数 —— 但形状必须留成二维，否则你以后喂多维数据时要改代码。
`W2[j]` 只接一个隐藏神经元的标量输出，一维就够。这两句话合起来就是 §2.9 那条"形状是数据决定的，不是习惯"。

```python
scale1 = 1.0 / n_in ** 0.5
scale2 = 1.0 / n_hidden ** 0.5
```

随机权重若按 $\mathrm{std}=1$ 初始化，加权和 $z=\sum_k W_k x_k$ 的方差是

$$\operatorname{Var}(z)=\sum_k \operatorname{Var}(W_k x_k)=n\,\sigma_W^{2}\operatorname{Var}(x)$$

（独立、零均值）。要让 $z$ 的方差和 $x$ 一个量级，就得取 $\sigma_W=1/\sqrt n$ ——
这就是那两行的全部来历，和阶段 3 里 `Linear` 用 `std*sqrt(2/fan_in)` 是同一件事。
本阶段 $n_{in}=1$，所以 `scale1` 恰好是 1（第一层其实没做缩放，因为它只有一个输入）。

`b1`、`b2` 从 **0** 开始，不从随机开始：bias 只负责"平移"，从 0 起步是最短路径；
随机起点等于先给模型一个没来由的偏移，前期梯度全在纠正它。

**这套记账以后每一步都要用**，问法完全一样，只是数字变大：

| 阶段 | 那层的参数 | 怎么数 |
|---|---|---|
| 阶段 3 `Linear(in_f, out_f)` | $W$ 是 $(out, in)$，$b$ 是 $(out,)$ | 每个输出神经元 = 对 $in$ 个输入加权 + 一个平移，和上表同构，只是把 for 循环换成一次矩阵乘 |
| 阶段 4 `CausalSelfAttention` | q/k/v/proj 四个 $d\times d$，其中 k 没有 bias | $4d^{2}+3d$ —— 少掉的那个 $d$ 是 §3.4 里被数学判死的 $b_k$ |
| 阶段 4/5 每个 Block | 注意力 + MLP（两个 $d\times 4d$）+ 两个 RMSNorm 的 $d$ | $12d^{2}+10d$，乘 $L$ 层再加词表 $Vd$，就是判据里那条参数量对账 |

以后你打开任何一个模型，第一件事就是列这张表：**每个参数在式子里是哪一项，删了会怎样**。
数不出这张表的时候，说明你还没真的看懂它。

| 默认 | 快速下降后变平 | 正常 |

**看曲线形状判断病因**，这个技能从阶段 2 开始练，到阶段 6 训真模型时每天都要用。

### 3.3 `loss()`：为什么除以点数

$$L=\frac1N\sum_{i}\bigl(f(x_i)-y_i\bigr)^{2}$$

用 mean 而不是 sum，是为了让梯度的尺度**与 batch 大小无关**。用了 sum，等效于
把 lr 放大 $N$ 倍 —— 症状是"一开始就炸"。阶段 3 的 `CrossEntropy` 里那个
`/ count` 是同一个约定的延续，判据"均匀 logits 的 loss $=\ln V$"就是它的守门人。

### 3.4 `parameters()` 与 `zero_grad()`：为什么必须存在

你的算子用 `+=` 累加梯度（这是对的：一个 Value 会被多条路径用到），所以
**必须由谁把它清成 0**。`zero_grad()` 就是这个"谁"。`parameters()` 存在的意义是
让训练循环不必知道网络内部长什么样 —— 加一层不用改循环。这两行是"框架"的雏形：
阶段 3 的 `Module.parameters()`、阶段 5 的 `optimizer.zero_grad()` 是它们的直接升级。

顺带记住：梯度累积（几条小 batch 攒一次更新）以后会**故意**利用"不清零"，
那时它是特性；现在它是 bug。同一个机制，两种用法，别混。

### 3.5 `predict()`：为什么单独存在

`forward()` 每次都会建一张新图（分配几百个 Value 对象、留下 `_prev` 引用），
而预测只需要数值。`predict()` 走的是同一条路径但只取 `.data`，
所以它慢得和训练一样、但语义上明确"这是推理"。
以后写 KV cache（进阶手册 §9）就是为了干掉这种重复建图。

### 3.6 为什么这里加宽不加深

12 个点、8 个隐藏神经元就够：$y=\sum_j W_{2j}\tanh(W_{1j}x+b_{1j})+b_2$ 是 8 段
可调的 S 形台阶拼曲线，宽度直接换成"能弯几次"。深度在标量引擎里代价极高
（每多一层，图上的节点数和 Python 调用都翻倍），而且会引入梯度消失这个新问题。
所以：**阶段 2 用宽度，阶段 5 之后用深度 + 残差**，残差正是为了让深度可用而存在的。

### 3.7 参数为什么要有 `label`

`gradient_check_graph` 失败时打印的就是 label：

```
      W1[2][0]: 解析 +0.1234567  数值 +0.1234567  相对误差 3.1e-11
      W2[3]:    解析 +0.0000000  数值 -0.0048213  相对误差 1.0e+00   ← 对不上
```

"第 3 个隐藏神经元的输出权重错了"——这句话能直接把你带到那一行代码。
没有 label 的话，你只知道"25 个参数里有一个错了"。养成给参数命名的习惯。

## 4. TODO-2A：`ScalarMLP.forward`

**契约**：`forward(x)` 接一个 float（n_in=1），返回一个 `Value`（预测值）。
每调一次就**新建一张图**，因为图的叶子必须包含参数对象本身。

结构就是两次加权求和，中间可选一次 `tanh`：

$$z_j = b_{1j} + \sum_k W_{1jk}\,x_k \qquad (j = 0 \ldots n_{\text{hidden}}-1)$$

$$y = b_2 + \sum_j W_{2j}\,h_j, \qquad h_j = \begin{cases}\tanh(z_j) & \text{activate}\\ z_j & \text{否则}\end{cases}$$

写的时候注意三件事：

1. 起点用 `self.b1[j]` 而不是 `Value(0)` —— 少加一个 bias 是本阶段最容易犯的错，
   症状是拟合曲线的形状对但整体偏移。
2. `self.activate` 决定中间那步。对照组靠它，不要把它简化掉。
3. 累加用 `z = z + ...`（Value 的 `+` 会建新节点），不是 `z += ...` 的浮点语义 ——
   两者在你这儿等价，但请写成前者，读代码时一眼是"建图"。

**自检**：`ScalarMLP().forward(0.5).data` 应该是个有限小数；
`ScalarMLP(activate=False)` 的输出对 x 必须是严格线性的（两个不同 x 的斜率一致）。

<details>
<summary>参考答案 · TODO-2A <code>ScalarMLP.forward</code>（判据没过之前别点开）</summary>

```python
    def forward(self, x: float) -> Value:
        vals = [x] if not isinstance(x, (list, tuple)) else list(x)
        hidden = []
        for j in range(self.n_hidden):
            z = self.b1[j]                          # 起点是 bias，不是 Value(0)
            for k in range(len(vals)):
                z = z + self.W1[j][k] * vals[k]
            hidden.append(z.tanh() if self.activate else z)
        out = self.b2
        for j in range(self.n_hidden):
            out = out + self.W2[j] * hidden[j]      # 累加 = 建图；写等号就只剩最后一个神经元
        return out
```

两个自查：`ScalarMLP(activate=False)` 的输出对 $x$ 必须严格线性（换两个 x 算斜率应当一致）；
`ScalarMLP()` 的 `forward(0.5)` 必须是有限数。第二版里 `out = out + ...` 而不是 `out += ...`，
在这儿两者等价，但写成前者，读代码时一眼就知道"这是在建图"。

</details>

## 5. TODO-2B：`train_mlp`

和阶段 1 的 `fit_by_autograd` 是同一个循环，参数从 2 个变成 25 个：

```flow
**清梯度** —— `model.zero_grad()`
↓
**正向** —— `loss = model.loss(xs, ys)`
↓
**反传** —— `loss.backward()`
↓
**算这一轮的学习率** —— `lr_t = ...`
↓
**走一步** —— 对每个参数 `p`：`p.data -= lr_t * p.grad`
```

返回每一轮的 `loss.data` 列表（曲线），判据要用 `curve[0] / curve[-1] ≥ 80`。
`log_every` 非 0 时调 `print_progress(it + 1, iters, every=log_every, prefix=prefix)`。

**一个容易漏的点**：`loss.backward()` 要在**清梯度之后、更新参数之前**调用。
顺序写成"更新 → 清 → backward"的话，第一轮会用 0 梯度，第二轮开始就用错了梯度，
症状是 loss 降得动但收敛明显变差 —— 又是只有判据能抓出来的那类错误。

<details>
<summary>参考答案 · TODO-2B <code>train_mlp</code></summary>

```python
    curve = []
    for it in range(iters):
        model.zero_grad()                 # ① 清
        loss = model.loss(xs, ys)         # ② 建图 + 正向
        loss.backward()                   # ③ 反传
        curve.append(loss.data)           # ④ 记账（float，长度 = iters）
        lr_t = lr / (1.0 + decay * it / iters)          # it=0 → lr；it=iters → lr/(1+decay)
        for p in model.parameters():      # ⑤ 逐个走一步
            p.data -= lr_t * p.grad
        if log_every:
            print_progress(it + 1, iters, every=log_every, prefix=prefix)
    return curve
```

和阶段 1 的 `fit_by_autograd` 唯一的结构差别：参数从"你手里那两个变量"变成
`model.parameters()` 这个列表，所以清零和更新都要遍历。`loss` 必须在循环**里面**新建 ——
提到循环外就等于把 4000 轮串成一张巨图，`backward()` 一次走完整条历史，既慢又不对。

</details>

## 6. TODO-4：`tanh`

（定义、导数、饱和、和 sigmoid 的关系都在 §2.3–§2.4；这一节只讲怎么写。）

照 `exp`/`relu`/`sigmoid` 的模板三行：

* 正向：`t = math.tanh(self.data)`
* 反向：$\partial\tanh(x)/\partial x = 1 - t^{2}$（用 $t$ 自己，不用 $x$）

**为什么 tanh 会让梯度变小**：$1-t^{2}$ 在 $|t|\to 1$ 时趋近 0，也就是饱和区梯度趋 0。
这就是深网络"梯度消失"的来源之一，也是后来 transformer 选 GELU/RMSNorm + 残差的动机。
阶段 3 的 GELU 也是同样的形状，只是饱和没那么狠。

写完跑判据；`tanh` 的正确性会被"梯度校验(25 参数 MLP)"这条直接查出来。

这句话值得亲手拖一遍：下面这张图把 `tanh` 和它的导数 `1−t²` 画在一起，拖 x 到 ±4 以外，
看导数塌到 1e-7 量级。更要紧的是「层数 L」和「权重尺度 w」两根滑杆 —— 它**真算** L 层连乘的
梯度，在对数坐标上画出那条衰减直线，并告诉你第几层就塌穿 float32 的下限（1.18e-38）。
打开 ReLU / GELU 两个对照开关，三条衰减曲线叠在一起看，这就是后来 transformer 换掉 tanh 的
全部理由。

@@fig tanhsat@@

<details>
<summary>参考答案 · TODO-4 <code>Value.tanh()</code></summary>

```python
    def tanh(self):
        t = math.tanh(self.data)
        out = Value(t, (self,), "tanh")

        def _backward():
            self.grad += (1.0 - t * t) * out.grad

        out._backward = _backward
        return out
```

和 `exp`/`relu`/`sigmoid` 是同一个模板：算正向 → 建 out → 写规则 → 挂上去 → 返回。
规则里用的是 **`t`（正向的结果）而不是 `self.data`**，这就是 §2.4 说的"用值表示导数"：
省一次 `math.tanh`，而且 $1-t^2$ 在 $|t|\to 1$ 时趋 0，饱和区梯度自动变小。

</details>

## 8. 常见失败模式对照表

| 症状 | 病因 | 修法 |
|---|---|---|
| 三组 MSE 全都 ≈ 0.217 | `activate` 没起作用（forward 里没分支，或总走 False 分支） | 检查 §4 第 2 点 |
| MLP MSE 停在 0.05 左右且曲线末端有毛刺 | decay=0，在谷底震荡 | 用 `decay=3.0, iters=6000` |
| MLP MSE 比线性还差、或 nan | lr 太大发散 | 回到 0.1；确认 `train_mlp` 里减的是 `lr_t` |
| 梯度校验里 `b1[j]` 全对、`W1` 全错 | forward 的 `z` 起点用了 `Value(0)` 后忘了加 bias，但梯度从别处流过来 | 用 §4 自检：两个不同 x 检查斜率与截距 |
| 梯度校验里 `b2` 的解析梯度是 0 | `out = self.b2` 后面被覆盖而不是累加 | 确认循环里是 `out = out + W2[j]*hidden[j]` |
| loss 下降倍数不足 80 但 MSE 达标 | 起点 lr 或 iters 改动 | 按脚本默认参数跑，别"顺手优化" |
| `TypeError: object of type 'float' has no len` | `forward` 里对 x 用了列表操作 | 脚本里那行 `isinstance(x, (list, tuple))` 的判断照抄 |
