# Transformer 课程设计：先完整 GPT，再扩展原版

本文件记录 2026-11-07 确认的课程方向，供后续教程实现使用；不表示以下章节均已上线。现有个人代码、草稿和成绩保持不变。

## 学习终点

用 Python 与 NumPy 手写一个前向、反向、训练和生成均完整的 decoder-only 模型；再复用模块实现原版 encoder-decoder。能够说明每个张量的轴、每条梯度路径，以及两种架构的信息流差异。核心计算不使用 PyTorch、自动求导或现成注意力接口。

架构类型与模块变体分开讲。decoder-only 不必使用 RMSNorm 或 RoPE；encoder-decoder 也不由某一种位置编码定义。主线继续沿用现有课程的可学习位置嵌入、RMSNorm、GELU、Pre-Norm，明确它是一套教学 GPT 配置，不冒称复现某个完整产品模型。原版复现另用正弦位置编码、LayerNorm、ReLU 和 Post-Norm。

## 第一至第四部分：保留现有基础，补齐宏观对照

- 第一部分：并列展示 decoder-only 与 encoder-decoder 的完整结构图；标明训练与生成的数据流，说明自注意力与交叉注意力的 Q/K/V 来源。此处要求看懂，不要求立即实现两套模型。
- 第二部分：NumPy、轴、广播、批量矩阵乘法、reshape/transpose、复制、重复索引累加、随机数与多头张量。
- 第三部分：标量自动微分与标量网络继续暂缓，不作为后续必修前置。
- 第四部分：Parameter/Module、初始化、Linear、Embedding、GELU、RMSNorm、MLP 的完整前向、缓存、反向与梯度累加。

## 第五部分：概率、损失与梯度入口

实现稳定 Softmax、Softmax 的向量—雅可比乘积、log-sum-exp、整数标签交叉熵。推导平均损失的 logits 梯度，说明平均因子只应用一次。输入 logits 为（B,T,V），标签为（B,T），损失为标量，反向为（B,T,V）。

验收：极大 logits 不溢出；每个位置概率和为 1；梯度沿词表轴之和为 0；更换目标标签会改变正确位置的梯度。有限差分的误差分析放在拓展，梯度正确性检查仍保留。

## 第六部分：因果注意力与多头注意力

依次实现 Q/K/V 投影、按 √d 缩放的分数、因果掩码、Softmax、value 加权、多头合并与输出投影。完整推导并实现 dV、dA、dS、dQ、dK，以及自注意力中输入的三路梯度相加。

默认样例至少采用 B=2、H=2、T=3、d=2。动画跟踪同一份样例，从某个 query 行的分数到概率再到输出，允许切换 batch/head/query；不省略其他切片。

验收：输出及全部梯度正确；未来概率为零；改变未来 token 不影响之前位置；多头拆分与合并坐标对应正确。padding mask 留到变长序列章节，不与因果掩码混为一谈。

## 第七部分：完整 decoder-only 模型

组合 Pre-Norm Block、两条残差路径、多个 Block、token 与位置嵌入、最终归一化和输出头。手写反向顺序；残差分支梯度相加，位置梯度沿 batch 求和，共享 token embedding 的查表梯度与输出头梯度累加。

验收：B、T、C 均大于 1；至少两层；参数递归收集与去重正确；所有可训练参数收到正确梯度；共享权重只更新一次；模型满足因果性。模型组装使用个人前置实现，不自动注入参考答案。

## 第八部分：训练、验证与可恢复实验

实现字符级 tokenizer、连续数据划分、移位目标、批次采样、SGD 对照、AdamW、全局梯度裁剪和学习率调度。先固定小批次过拟合，再用独立验证集检查泛化。说明每步清零、前向、损失、反向、裁剪、更新的顺序。

检查点保存模型、优化器状态、步数、配置、词表与随机数状态。训练/验证划分先于窗口采样，窗口不得跨边界；验证不更新参数或训练随机数状态。

验收：小批次损失明显下降；参数确实变化；验证无更新；恢复后下一批次和下一次更新与连续运行一致。训练曲线区分训练与验证，并展示实际配置与随机种子。

## 第九部分：生成与第一个完整成果

实现最后位置 logits 选择、温度、top-k、随机采样、逐 token 追加和上下文截断。明确 teacher forcing 训练与自回归生成的区别。记录裁剪上下文时位置编号重置的约定及局限。

验收：输出保留前缀；新增长度正确；编号合法；固定种子可复现；采样不更新权重。至此交付第一个可本地训练、保存、恢复和生成的小型 GPT，作为学习里程碑。

## 第十部分：补齐原版差异模块

实现 LayerNorm 的完整反向，与 RMSNorm 比较减均值路径；实现正弦位置编码并解释它无可训练位置参数；实现 ReLU 与 Post-Norm 子层；实现训练/评估模式下的 Dropout。

交叉注意力使用不同的目标长度与源长度：Q 为（B,H,T_target,d），K/V 为（B,H,T_source,d），注意力图为（B,H,T_target,T_source）。投影参数独立，不能把自注意力同一输入的假设套进来。反向分别返回 decoder 输入梯度与 encoder memory 梯度。

验收：T_target ≠ T_source；Q/K/V 梯度正确；源 padding 不被读取；LayerNorm 在最后特征轴独立计算；Dropout 评估模式恒等，反向使用前向同一张掩码。

## 第十一部分：完整 encoder-decoder

组装原版结构：encoder 的双向自注意力与前馈子层；decoder 的因果自注意力、交叉注意力与前馈子层。明确源 padding、目标 padding、因果可见性与损失忽略位置各自作用，避免全遮蔽行产生 NaN。使用 BOS/EOS/PAD，并在训练时右移目标。

反向将各 decoder 层交叉注意力返回的 memory 梯度相加，再送回 encoder；不能只回传最后一个 decoder 层的贡献。

先训练可控任务：序列复制、顺序反转，使用多种真实长度和 padding。按未见序列的整句正确率验收，并检查自回归停止于 EOS。翻译作为可选后续任务，不以下载大语料作为完成架构学习的前置。

最终能够画出两种架构，逐处指出模块复用、额外参数、信息可见性与反向路径。

## 第十二部分：现代变体与推理优化

在正确的基线上逐项替换并测评：RoPE（含旋转的反向）、SwiGLU、GQA 与 KV cache。每次只改一个因素，展示参数量、缓存形状、输出与速度变化。

KV cache 先在上下文范围内验证逐 token 输出与无缓存前向一致，再解释位置偏移、缓存扩展与滑动窗口的差异；不能把重置位置编号的截断基线直接当作缓存等价目标。性能比较注明尺寸、运行环境与测量方式。

这一部分属于进阶路线；不以完成所有现代变体作为掌握两种基本架构的条件。

## 所有章节共用的页面与测评约定

1. 单一连续内容区：定义与推导 → 样例输入输出 → 同样例动画 → 动手实现 → 测评结果 → 下一任务。仅代码编辑框可调整尺寸，宽度不撑开页面。
2. 每项练习写清函数签名、参数类型、每条轴的含义、返回值、缓存、状态修改和禁止修改的对象。参数更新任务明确声明哪些状态应改变。
3. 提供完整可本地运行的 TODO 骨架；完整参考实现默认折叠；前置依赖引用个人代码。新建缺失文件，不覆盖已有个人练习。
4. 默认高维样例各语义轴大于 1；变长任务展示不同源/目标长度、不同 padding 长度。单样本只用于边界测试。
5. 测评说明与结果共用一份用例列表，通过收起、失败展开；当前代码对应的通过状态明显可见，下一任务放在结果末尾。
6. 公式和必要推导留在正文；误差分析留在拓展；不展示教学设计过程等学习者无须阅读的说明。
7. 网站提供可调参数实验：配置检查、真实执行、曲线和采样结果。实验执行与任务通过分开，不能用参考模型的成功替代个人实现的通过。
