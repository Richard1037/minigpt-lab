    2. 必要理论：loss、梯度、链式法则

    2.1 loss 就是"错得多离谱"的一个数字

    $$L(a,b)=\frac{1}{N}\sum_{i=1}^{N}\bigl(a x_i + b - y_i\bigr)^{2}$$

    一个标量。训练 = 让这一个数字变小。所有复杂度都来自"怎么知道该往哪边调"。

    2.2 梯度 = 变化率

    $\partial L/\partial a$ 读作"a 动一点点，L 动多少倍"。所以把 a 往梯度的反方向挪，loss 就降：

    $$a \leftarrow a - \eta\,\frac{\partial L}{\partial a}$$

    $\eta$ 是学习率（代码里叫 lr），决定一次挪多远。就这么一行，它就是"训练"的全部内容。

    2.3 链式法则：把复合函数拆成局部导数相乘

    对 $L=\frac1N\sum_i e_i^{2}$，其中 $e_i = a x_i + b - y_i$，链式法则给出

    $$\frac{\partial L}{\partial a}=\frac1N\sum_i 2e_i\,x_i,\qquad \frac{\partial L}{\partial b}=\frac1N\sum_i 2e_i$$

    外层的导数乘内层的导数 —— 这就是"链"。反向传播干的就是这件事，只不过它把这条链 沿计算图自动走完，并且是"从 loss 往参数方向"走（所以叫 back-ward）。

    2.4 一个你待会儿会手算的例子

    设 $a=2$，$b=3$，$L=(ab)^{2}$。图上有四个节点：

    $$\frac{\partial L}{\partial p}=2p=12,\qquad \frac{\partial p}{\partial a}=b=3,\qquad \frac{\partial p}{\partial b}=a=2$$

    再乘一次链：∂L/∂a = 12 · 3 = 36，∂L/∂b = 12 · 2 = 24。

    现在换成"自动微分怎么走"：loss.grad 起手是 1，pow2 节点把 1 · 2*p* = 12 交给 p （注意：是 p.grad += 12，而不是"p 的梯度等于 12"这个事实本身 —— 它是累加到 p 上的）， mul 节点再把 p.grad 分发：a.grad += b p.grad = 3 · 12 = 36，b.grad += a p.grad = 24。

    关键结论：每个节点的规则只需要知道"我上游传下来多少"（out.grad）和"我的局部导数"， 不需要知道整张图长什么样。这就是为什么反向传播可以一层一层写。

    6. TODO-3：backward() —— 本阶段最需要想清楚的地方

    在测评台里打开 →

    契约：some_value.backward() 执行后，从它往下的每个叶子的 .grad 都等于 $\partial(\text{它})/\partial(\text{叶子})$。无返回值。

    三件事，顺序不能换：

  • 拓扑排序：从 self 出发递归走 _prev，把节点按"孩子在前、父亲在后"排进列表 topo。
    1. 为什么要去重：一个 Value 可以被多个下游用到（比如 b1 被整个图用到），

    不去重就会执行多次它的规则，梯度翻倍。用 id(v) 做集合判断，别用 v in seen （Value 没定义 __eq__/__hash__，默认按 id，但显式写 id() 更清楚也更保险）。

    • 为什么"后序"就够用：后序遍历保证每个节点出现在它所有父节点之前，

    于是倒过来走就是"从 loss 往参数"的正确顺序。（严格说后序在这里是充分必要的， 因为图是 DAG，且规则只在被调用时读取 out.grad。）

  • 起点：self.grad = 1.0。因为 $\partial L/\partial L = 1$，这是整条链的源头。

    • 这一行漏了，全部梯度是 0，而且不会报错。

  • 逆序执行规则：for v in reversed(topo): v._backward()。

    • 顺序写成正序的话，节点在还没收到上游梯度时就被摊派，梯度偏小 —— 而且 loss 依然会降， 只是降得慢，只有梯度校验能抓。

    下面这张图把"逆拓扑序"播给你看：按 reversed(topo) 逐个节点把梯度摊到操作数上，每步显示各节点当前的 .grad；切到"错误顺序"（正序 / 少 seed 一遍），梯度当场漏掉、和解析值对不上。
