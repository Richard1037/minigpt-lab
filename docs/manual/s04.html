1. 这一步在干什么

前面的层都是逐位置的：第 $t$ 个 token 的输出只看它自己。注意力让 token 之间互相看一眼： 每个 token 提出一个查询，和所有（允许的）token 的键比相似度，按相似度加权收集它们的值。

$$s_{ij}=\frac{q_i\cdot k_j}{\sqrt{d_h}} \;\longrightarrow\; a_{ij}=\mathrm{softmax}_j(s_{ij}) \;\longrightarrow\; \mathrm{out}_i=\sum_j a_{ij}\,v_j$$

"因果"= 位置 $i$ 只允许看 $j\le i$。这一条是自回归生成的根本原因：训练时若允许看后面， 模型直接抄答案，loss 低得离谱、生成时一塌糊涂。

    11.1 为什么是 q/k/v/proj 四个矩阵

    投影角色拿掉会怎样
    $W_q$提出查询没有"问什么"，注意力退化成固定的键匹配
    $W_k$生成索引与 $W_q$ 必须分开，否则相似度只剩一个投影在决定
    $W_v$携带内容只能按相似度搬运原向量，"关注谁"和"取走什么"绑死
    $W_{proj}$混合各头输出各头并列而不交流，"多头"只多参数、不多能力

    索引和内容必须是两种东西：若 k 与 v 共用一个投影，模型只能表达"和我相似的词"， 表达不了"我该关注的那个词携带什么"。

    四个都是 Linear(C, C)，切头不改变计算，只是把 $H$ 个独立的低维注意力并排放进一个张量。 k 不要 bias，所以参数量是 $4C^{2}+3C$ —— 理由见 §11.4 ④。

    11.2 除 $\sqrt{d_h}$ 是方差算术，不是玄学系数

    $q\cdot k=\sum_{i=1}^{d_h}q_ik_i$，各维独立、零均值、方差 1：

    $$\operatorname{Var}(q\cdot k)=\sum_{i=1}^{d_h}\operatorname{Var}(q_ik_i)=d_h \quad\Longrightarrow\quad \operatorname{std}(q\cdot k)=\sqrt{d_h}$$

    写法分数方差后果
    除 $\sqrt{d_h}$$1$分数落在 $\pm 3$ 量级，softmax 有梯度
    不除$d_h$$d_h=64$ 时分数动不动 $\pm 16$，softmax 近似 one-hot，反向梯度 $\approx 0$
    除 $\sqrt C$$d_h/C=1/H$$H=1$ 时全对，$H>1$ 时分数被系统性压平

    最后一行是最难自查的错：单头判据全绿、多头才露馅。项数是每个头自己的 $d_h$（$C=H\,d_h$），不是 $C$。

    11.3 掩码：为什么必须在 softmax 之前，为什么是 $-10^{18}$

    因果 softmax 的分母只该含 $j\le i$：

    $$a_{ij}=\frac{\exp(s_{ij})}{\sum_{j'\le i}\exp(s_{ij'})}$$

    掩码就是把 $j>i$ 从分母里踢出去，所以只能在 softmax 之前动手。

  • 加在之后（先归一化再乘 0）：每行和不再是 1，得重新归一化，等价于把未来格子的权重摊回

    • 过去格子上 —— 因果性失效。

  • 用 -inf：至少有一处 $0\cdot\infty$ 就出 $\mathrm{nan}$，反向一路传染。
  • 用 -1e18：$\exp(-10^{18}-\max)$ 在 float64 里精确为 0 → 概率精确 0 → 梯度精确 0，

    • 不需要任何清理。

  • 清理反而是坑：np.where(mask==0, 0, g) 里 mask==0 是允许的位置，条件写反就把

    • 该留的梯度清掉了。

    (1,1,T,T) 的两个 1 是 batch 和 head 维，让同一张掩码广播到所有样本、所有头。

    11.4 已给代码里的六件事

    ① _split_heads：先 reshape 再 transpose。

    reshape 不搬数据，只是把 C 重新解释成 H 段；transpose 只改轴的记账。反过来先 transpose 再 reshape：转置后的数组不连续，reshape 会复制并按新顺序重排 —— 形状照样对、 数值是乱的。前向看着"也是个合理的向量"，只有 gradcheck 抓得住。合头是严格逆操作，backward 里对 $g_q/g_k/g_v$ 走同样两步。

    ② _causal_mask：np.triu(..., k=1) 与 (1,1,T,T)。

    k=1 取严格上三角，对角线保留 —— 位置 $i$ 必须能看自己；写成 k=0 就变成"不许看自己"， 模型学成"预测前一个 token 的前一个 token"。乘 NEG_INF 后允许处仍是 0，加到分数上无影响。 dtype 跟着分数走：$-10^{18}$ 在 float32 上限（$3.4\times10^{38}$）之内，换精度不用改这一行。

    ③ _softmax_rows 和阶段 3 的 CrossEntropy 是同一招。

    减最大值、取指数、除行和，三行完全同构；区别只在返回什么 —— 这里返回概率（要拿它加权求和）， CrossEntropy 返回 loss 并缓存概率。两处都靠 $\exp(-10^{18}-m)=0$ 把禁止位置干净地抹掉。

    ④ $b_q$ 活着而 $b_k$ 死了：行与列的不对称。

    $$\frac{\partial L}{\partial b_q}=\sum_{i}\Bigl(\sum_j g_{ij}\,k_j\Bigr),\qquad \frac{\partial L}{\partial b_k}=\sum_{j}\Bigl(\sum_i g_{ij}\Bigr)q_i$$

    softmax 的守恒性质给出每行 $\sum_j g_{ij}=0$，于是 $b_k$ 那条整个消失；$b_q$ 那条是不同 $k_j$ 的加权和，抵消不掉。一句话：$b_k$ 给整行加同一个常数（softmax 不变），$b_q$ 改变行内各列的 相对分数（真变）。$b_v$ 也活着 —— 它作用在加权和的结果上。

    ⑤ proj 是 $H$ 个头唯一的交流点。

    reshape 只把各头并排放好，没有任何信息交换。没有 proj，多头就等价于 $H$ 个互不相干的 低维网络；它同时把结果混回主干需要的 $C$ 维表示，所以也是残差出口缩放的对象。

    ⑥ 合头必须过 proj，scale 用 $d_h$ 不用 $C$。

    两处都在 §2 的五条决定里，数字的来历见 §11.2；判据盯的是参数量与多头 gradcheck。

    11.5 softmax_backward：那个减项从哪来

    从定义出发：

    $$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}} \;\Longrightarrow\; \frac{\partial p_i}{\partial z_k}=p_i\bigl(\delta_{ik}-p_k\bigr)$$

    链式法则（记 $\mathrm{gp}_i=\partial L/\partial p_i$）：

    $$\frac{\partial L}{\partial z_k}=\sum_i \mathrm{gp}_i\,p_i(\delta_{ik}-p_k) =p_k\Bigl(\mathrm{gp}_k-\sum_i \mathrm{gp}_i p_i\Bigr)$$

    两个自查事实都不用等 gradcheck：

  • $\mathrm{gp}$ 整行等于同一个常数 $c$：$g=p(c-c\sum p)=0$。给一行所有分数加常数不改变

    • softmax，梯度就必须是 0 —— 和 $b_k$ 死参数同一个性质。

  • 正向均匀 $p_i=1/n$：$g=\frac1n(\mathrm{gp}-\overline{\mathrm{gp}})$，就是"每行减均值"。

    • 为什么漏减项难发现：return g_probs * probs 仍是一个"看起来对"的局部梯度，loss 照样降； 只有和有限差分逐格比，才在 q/k 上暴露 $10^{-1}$ 量级的相对误差。

    它和 RMSNorm 里那个 $s$ 同源：两者都在减掉"被约束钉住"的方向。softmax 钉住每行和 $=1$， RMSNorm 钉住每行长度 $=\sqrt C$，所以反向里都出现一个"减去本行加权均值"的项 （阶段 3b §11.2）。
