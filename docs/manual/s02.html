1. 这一步在干什么

12 个点，y = sin(x)，x ∈ [-3, 3]。学出这个函数。

脚本会跑三组对照，这是本阶段真正的内容：

组模型预期
1没有隐藏层的线性模型撞墙：MSE ≈ 0.217
24 个神经元、两层线性，中间不加激活撞同一面墙：MSE ≈ 0.217
3同样结构，中间加一个 tanh墙消失：MSE ≈ 0.005

第 2 组是重点。你会看到"我把网络加深了、参数变多了，结果一模一样"， 这件事比任何公式都更能让你理解什么叫模型容量。

2. 必要理论

2.1 线性 ∘ 线性 = 线性

  • 第一层：$z = W_1 x + b_1$
  • 第二层：$y = W_2 z + b_2$
  • 代进去：

    • $$y \;=\; W_2\bigl(W_1 x + b_1\bigr) + b_2 \;=\; \underbrace{(W_2 W_1)}_{\text{还是一个矩阵}}\;x \;+\; (W_2 b_1 + b_2)$$

    所以多层线性叠起来等价于一层，参数再多也没用 ——所以多层线性叠起来等价于一层，参数再多也没用 —— 它只能画出直线（在这里是一条水平线附近的直线，sin 的波峰波谷一个都抓不住）。 加深层数不买新能力，加非线性才买。

    2.2 激活函数是"能不能表达"的开关

    tanh 夹在中间之后，网络变成

    $$y = \sum_{j} W_{2j}\,\tanh\bigl(W_{1j} x + b_{1j}\bigr) + b_2$$

    —— 8 个 S 形的、可平移可缩放的小台阶拼起来，就能逼近任意连续曲线（这是通用近似定理的直觉版本）。 sin 的 12 个点用 8 个隐藏神经元足够。

    transformer 里对应的位置是 FFN 中间的 GELU，以及注意力打分后的 softmax。 如果哪天你的 transformer loss 卡住不动，第一反应不该是"再训久一点"， 而是"我的非线性是不是被我不小心拿掉了"。

    2.3 激活函数全家福

    从这一节起，讲的是已经写在你眼前的代码。手册不能只给"你要写的东西"的契约， 却把"给你的东西"当黑盒 —— 那等于让你自己反推，反而更费时间。 exp / relu / sigmoid 是三个样例（和阶段 1 §3 里那条 __add__ 一个地位：演示闭包规则）， tanh 才是要你写的（TODO-4，阶段 2）。但四个都得读懂，因为后面每次 loss 卡住， 第一个被怀疑的就是它们。

    函数定义导数值域性格本项目在哪儿用它
    exp$e^{x}$$e^{x}$$(0,+\infty)$求导还是自己；$x\gtrsim 709$ 溢出__truediv__ 和 sigmoid 的零件；softmax 的心脏
    relu$\max(0,x)$$\mathbf{1}[x>0]$$[0,+\infty)$最便宜；负半轴梯度恒 0教学对照（FFN 最终用 GELU）
    sigmoid$\sigma(x)=\dfrac{1}{1+e^{-x}}$$\sigma(x)\bigl(1-\sigma(x)\bigr)$$(0,1)$像概率；饱和得早二分类输出；注意力里被 softmax 取代
    tanh$\tanh(x)=\dfrac{e^{x}-e^{-x}}{e^{x}+e^{-x}}=2\sigma(2x)-1$$1-\tanh^{2}(x)$$(-1,1)$零中心；饱和比 sigmoid 轻阶段 2 的主角；GELU 里也用它

    表里两个恒等式值得你亲手验一次（它们是"这几个函数是一家人"的证据）：

    $$\tanh(x)=2\sigma(2x)-1,\qquad \sigma'(x)=\sigma(x)\bigl(1-\sigma(x)\bigr)$$

    2.4 三条必须有的直觉

    一、饱和 = 导数趋 0 = 学不动。 $\sigma(8)=0.999665$，而 $\sigma'(8)=3.35\times10^{-4}$ —— 曲线已经躺平，梯度基本没了。 tanh 同样饱和但轻一些（$1-t^{2}$，$|t|\to1$ 才趋 0）。 以后 loss 卡住别只想着"再训久一点"，先看激活值是不是长期贴在两端。

    二、零中心（zero-centered）为什么重要。 sigmoid 的输出恒正。如果一层的输入全是正数，那么 $\partial L/\partial W = g^{\top}x$ 的 每一项都同号 → 这一层所有权重的梯度同号 → 更新只能"一起增"或"一起减"， 走的是锯齿形路线，而不是直指最优点。tanh 输出可正可负，relu 至少能把一半梯度归零而不是 全同号。这是历史上大家离开 sigmoid 的原因（比"tanh 更像线性"这种说法实在得多）。

    三、导数用"函数值自己"表示。 sigmoid 的反向写的是 s (1 - s)，tanh 的是 1 - tt —— 用的是正向已经算好的那个值， 不再求一次 exp。两个好处：省计算，而且这正是"forward 缓存中间量"这个约定的最早形态。 阶段 3 里你会把它写成 self._probs、self._xh，道理一模一样： 反向需要的东西，正向顺手存下来。

    2.5 relu 在 0 处不可导，代码里怎么选

    mask = 1.0 if self.data > 0 else 0.0 —— 在 $x=0$ 这个点上取了导数 0。 严格说 $\max(0,x)$ 在 0 处不可导（左导数 0、右导数 1），任选 0 或 1 都合法， 但整个项目必须一致：否则有限差分梯度校验会在 $x=0$ 附近给出"对不上"的假警报 （差分的 $\epsilon$ 会把点推到左或右半边）。这也是为什么本项目用 GELU 而不是 relu： GELU 处处可导，梯度校验干净。

    顺带记住 relu 的著名失效模式 —— 死神经元：一旦某个神经元的输入长期为负， 它的梯度恒 0，权重从此不再更新，这个单元就报废了。GELU / leaky relu 存在的一半理由在这里。

    2.6 exp 的溢出，和"减最大值"这一招

    $e^{709}=8.2\times10^{307}$ 已经贴着 float64 上限，$e^{710}$ 直接 OverflowError。 所以本项目从不直接对 logits 求 exp，而是先减每行最大值 $m$：

    $$\mathrm{softmax}(z_i)=\frac{e^{z_i-m}}{\sum_j e^{z_j-m}},\qquad m=\max_j z_j$$

    分子分母同乘 $e^{-m}$，值完全不变；但最大项变成 $e^{0}=1$，其余 $\le1$，不可能溢出。 这一招会在三处反复出现：阶段 3 的 CrossEntropy、阶段 4 的注意力打分、阶段 7 的采样。 判据"logits=900 不溢出"就是在查你有没有记住它。

    2.7 为什么注意力用 softmax 而不是"几个 sigmoid"

    softmax 强制 $\sum_j a_{ij}=1$：在第 $i$ 个位置，看向各处的权重加起来必须是 1。 sigmoid 每一列各自开关，和不为 1，于是 $\mathrm{out}_i=\sum_j a_{ij}v_j$ 的尺度会随 "有几个位置被打开了"漂移 —— 序列越长越明显。

    这个"每行和守恒"不是抽象美德，它在反向里必须被尊重： 阶段 4 的 softmax_backward 里那个减掉的项 $\sum_j(\mathrm{gp}_j p_j)$， 就是守恒约束的数学后果；同一个性质还让 $b_k$ 的梯度恒等于 0（一个死参数）。 看到"某处要减一个均值/加数"，条件反射就该想到"这是守恒约束"。

    2.10 怎么区分"容量不够"和"优化没调好"

    看 loss 曲线的形状，这个技能以后每次训练都要用：

  • 容量不够：前几十步快速下降，然后平在一个较高的值，无论训多久都不动。
  • lr 太大：曲线震荡，甚至发散（值越来越大 / 出现 nan）。
  • lr 太小：几乎是一条直线，降得极慢 —— 再等 10 倍时间才看得出是不是容量问题。

    • 阶段 1 的 lr 演示是第二种，本阶段的对照组是第一种。

    2.11 学习率衰减：为什么固定 lr 到不了最低点

    梯度下降在谷底附近的行为是"跨过谷底 → 梯度反向 → 再跨回来"。 只要 lr 不为 0，这个来回就停不下来，你看到的 loss 是谷底附近的一个震荡带， 而不是谷底本身。把 lr 随时间收小，就是"越走越慢，最后停在谷底"：

    $$\mathrm{lr}_t = \frac{\mathrm{lr}}{1 + d\,\dfrac{t}{T}}

    \qquad (d = \texttt{decay})$$

    $d=3$ 时末端的 lr 正好是初值的 1/4。

    脚本第 3 组用 decay=3.0 跑 6000 步；你可以把 decay 改成 0 再跑一次， 对比 MLP loss 下降倍数（要求 ≥80）会不会掉下来 —— 会掉。这个实验值得亲手做一次， 它比这段文字有用。阶段 7 的 warmup + cosine 是同一道理的放大版。

    3.1 __init__：为什么要造这些参数，以及为什么正好是这个数

    参数不是"先造好再说"，它们是你想表示的那个函数的直接翻译。先把式子写下来：

    $$y(x) = b_2 + \sum_{j=1}^{n_{\text{hidden}}} W_{2j}\;\tanh\!\bigl(b_{1j} + W_{1j}\,x\bigr)$$

    然后逐个问一句"删了会怎样"——这才是"为什么要它"的答案：

    参数个数式子里它是哪一项删了会怎样
    W1[j][k]$n_{\text{hidden}}\times n_{in}$$\tanh$ 里 $x$ 的系数：第 $j$ 个神经元"以多大倍率看第 $k$ 个输入"$z_j$ 与 $x$ 无关，整个网络输出一个常数 —— 连直线都画不出来
    b1[j]$n_{\text{hidden}}$$\tanh$ 的拐点位置（$z_j=0$ 发生在 $x=-b_{1j}/W_{1j}$）六个 tanh 全被钉在 $x=0$ 处翻转，网络只能表达关于原点对称的形状，$y=3x+1$ 这种就学不动
    W2[j]$n_{\text{hidden}}$第 $j$ 个神经元对输出的贡献，正负都能调没有求和，输出等于第一个神经元的 tanh，其它五个白造
    b21整体上下平移截距只能靠隐藏层硬凑，而隐藏层的和本来就受 $\tanh\in(-1,1)$ 限制

    所以总数是 $3\,n_{\text{hidden}} + n_{\text{hidden}}\,n_{in} + 1$：

  • n_hidden=6 → 19 个；
  • 判据里那句"梯度校验(25 参数 MLP)"用的是 n_hidden=8 → 25 个（$3\times8+8+1$）；
  • 对照组 n_hidden=1 只有 4 个，正好退化成 $ax+b$ —— 这就是 §2.1"线性∘线性=线性"的实物证据，

    • 也是为什么它必须学不动：它的参数集里根本没有能弯的东西。

    为什么 W1 是二维、W2 是一维：W1[j] 要接 $n_{in}$ 个输入，所以是"每行一个神经元"的矩阵； 本阶段 $n_{in}=1$，每行只有一个数 —— 但形状必须留成二维，否则你以后喂多维数据时要改代码。 W2[j] 只接一个隐藏神经元的标量输出，一维就够。这两句话合起来就是 §2.9 那条"形状是数据决定的，不是习惯"。

    随机权重若按 $\mathrm{std}=1$ 初始化，加权和 $z=\sum_k W_k x_k$ 的方差是

    $$\operatorname{Var}(z)=\sum_k \operatorname{Var}(W_k x_k)=n\,\sigma_W^{2}\operatorname{Var}(x)$$

    （独立、零均值）。要让 $z$ 的方差和 $x$ 一个量级，就得取 $\sigma_W=1/\sqrt n$ —— 这就是那两行的全部来历，和阶段 3 里 Linear 用 std*sqrt(2/fan_in) 是同一件事。 本阶段 $n_{in}=1$，所以 scale1 恰好是 1（第一层其实没做缩放，因为它只有一个输入）。

    b1、b2 从 0 开始，不从随机开始：bias 只负责"平移"，从 0 起步是最短路径； 随机起点等于先给模型一个没来由的偏移，前期梯度全在纠正它。

    这套记账以后每一步都要用，问法完全一样，只是数字变大：

    阶段那层的参数怎么数
    阶段 3 Linear(in_f, out_f)$W$ 是 $(out, in)$，$b$ 是 $(out,)$每个输出神经元 = 对 $in$ 个输入加权 + 一个平移，和上表同构，只是把 for 循环换成一次矩阵乘
    阶段 4 CausalSelfAttentionq/k/v/proj 四个 $d\times d$，其中 k 没有 bias$4d^{2}+3d$ —— 少掉的那个 $d$ 是 §3.4 里被数学判死的 $b_k$
    阶段 4/5 每个 Block注意力 + MLP（两个 $d\times 4d$）+ 两个 RMSNorm 的 $d$$12d^{2}+10d$，乘 $L$ 层再加词表 $Vd$，就是判据里那条参数量对账

    以后你打开任何一个模型，第一件事就是列这张表：每个参数在式子里是哪一项，删了会怎样。 数不出这张表的时候，说明你还没真的看懂它。

    3.3 loss()：为什么除以点数

    $$L=\frac1N\sum_{i}\bigl(f(x_i)-y_i\bigr)^{2}$$

    用 mean 而不是 sum，是为了让梯度的尺度与 batch 大小无关。用了 sum，等效于 把 lr 放大 $N$ 倍 —— 症状是"一开始就炸"。阶段 3 的 CrossEntropy 里那个 / count 是同一个约定的延续，判据"均匀 logits 的 loss $=\ln V$"就是它的守门人。

    3.4 parameters() 与 zero_grad()：为什么必须存在

    你的算子用 += 累加梯度（这是对的：一个 Value 会被多条路径用到），所以 必须由谁把它清成 0。zero_grad() 就是这个"谁"。parameters() 存在的意义是 让训练循环不必知道网络内部长什么样 —— 加一层不用改循环。这两行是"框架"的雏形： 阶段 3 的 Module.parameters()、阶段 5 的 optimizer.zero_grad() 是它们的直接升级。

    顺带记住：梯度累积（几条小 batch 攒一次更新）以后会故意利用"不清零"， 那时它是特性；现在它是 bug。同一个机制，两种用法，别混。

    3.5 predict()：为什么单独存在

    forward() 每次都会建一张新图（分配几百个 Value 对象、留下 _prev 引用）， 而预测只需要数值。predict() 走的是同一条路径但只取 .data， 所以它慢得和训练一样、但语义上明确"这是推理"。 以后写 KV cache（进阶手册 §9）就是为了干掉这种重复建图。

    3.6 为什么这里加宽不加深

    12 个点、8 个隐藏神经元就够：$y=\sum_j W_{2j}\tanh(W_{1j}x+b_{1j})+b_2$ 是 8 段 可调的 S 形台阶拼曲线，宽度直接换成"能弯几次"。深度在标量引擎里代价极高 （每多一层，图上的节点数和 Python 调用都翻倍），而且会引入梯度消失这个新问题。 所以：阶段 2 用宽度，阶段 5 之后用深度 + 残差，残差正是为了让深度可用而存在的。

    3.7 参数为什么要有 label

    gradient_check_graph 失败时打印的就是 label：

    "第 3 个隐藏神经元的输出权重错了"——这句话能直接把你带到那一行代码。 没有 label 的话，你只知道"25 个参数里有一个错了"。养成给参数命名的习惯。

    6. TODO-4：tanh

    在测评台里打开 →

    （定义、导数、饱和、和 sigmoid 的关系都在 §2.3–§2.4；这一节只讲怎么写。）

    照 exp/relu/sigmoid 的模板三行：

  • 正向：t = math.tanh(self.data)
  • 反向：$\partial\tanh(x)/\partial x = 1 - t^{2}$（用 $t$ 自己，不用 $x$）

    • 为什么 tanh 会让梯度变小：$1-t^{2}$ 在 $|t|\to 1$ 时趋近 0，也就是饱和区梯度趋 0。 这就是深网络"梯度消失"的来源之一，也是后来 transformer 选 GELU/RMSNorm + 残差的动机。 阶段 3 的 GELU 也是同样的形状，只是饱和没那么狠。

    写完跑判据；tanh 的正确性会被"梯度校验(25 参数 MLP)"这条直接查出来。

    这句话值得亲手拖一遍：下面这张图把 tanh 和它的导数 1−t² 画在一起，拖 x 到 ±4 以外， 看导数塌到 1e-7 量级。更要紧的是「层数 L」和「权重尺度 w」两根滑杆 —— 它真算 L 层连乘的 梯度，在对数坐标上画出那条衰减直线，并告诉你第几层就塌穿 float32 的下限（1.18e-38）。 打开 ReLU / GELU 两个对照开关，三条衰减曲线叠在一起看，这就是后来 transformer 换掉 tanh 的 全部理由。

    参考答案 · TODO-4 Value.tanh()

    和 exp/relu/sigmoid 是同一个模板：算正向 → 建 out → 写规则 → 挂上去 → 返回。 规则里用的是 t（正向的结果）而不是 self.data，这就是 §2.4 说的"用值表示导数"： 省一次 math.tanh，而且 $1-t^2$ 在 $|t|\to 1$ 时趋 0，饱和区梯度自动变小。
