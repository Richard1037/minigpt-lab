# 新版课程入口

在项目目录执行 `python webapp/pilot_server.py`，访问 http://127.0.0.1:8124/ 。使用已安装 NumPy 的 Python。

第一部分：模型与数据流、GPT 与原始 Transformer 对照。

第二部分：数组与类型、轴与归约、索引、广播、矩阵乘法、reshape、transpose、视图与复制、重复索引散射、随机数，以及保留 batch/head 的四维拆头与还原。

第三部分：标量自动微分与标量网络暂缓，原讲义和实现保留。

第四部分：Parameter/Module、初始化、Scale、Linear 前向、完整 Linear、Embedding、GELU、RMSNorm、MLP。

第五部分：稳定 Softmax、向量雅可比积、LogSumExp 交叉熵及平均梯度。

第六部分：先分步实现缩放打分、因果概率、加权输出，再完成 AttentionCore 前后向；练习多头还原后组合多头投影、Pre-Norm Block、残差、Dropout、LayerNorm 与原始 Transformer 对照。

第七部分：完整 GPT、位置嵌入、共享输出头的两路梯度、字符词表、移位标签和批次。

第八部分：全局梯度裁剪、AdamW、训练闭环、验证与可调参数实验室。

第九部分：温度/top-k、批量自回归生成、上下文滑窗、检查点与续训。

共有 51 个主线任务（262 项测评），另有 5 个拓展排错任务（19 项测评）。总计 56 个任务、281 项公开测评、53 个本地代码练习。公式推导在正文；数值误差分析在拓展。主线完成可训练的 decoder-only GPT；KV cache、BPE 和完整 encoder-decoder 不属于当前必修实现。

## 写代码与运行

- 在网站编辑后点“提交代码并测评”。个人草稿和当前代码对应的成绩存储在浏览器中。
- 点“保存到本地练习”才会更新 `exercises/` 中对应文件；旧文件先保存到 `exercises/backups/`。
- 本地直接编辑后点“读取本地文件”将它载入网页；本地命令为 `python exercises/对应文件.py`。
- MLP 依赖自己的 `layer_linear.py` 和 `layer_gelu.py`；网页使用这两个任务的个人草稿，本地使用这两个文件。请先完成并保存前置层。
- 训练实验室位于“第八部分 → 优化器与完整训练 → 训练闭环”页面末尾，使用个人模块。需要先完成采样/生成任务；实验不替代任务测评。
- 所有模块完成后，`python exercises/run_gpt.py corpus.txt --steps 100` 可用 UTF-8 语料训练并保存到 `runs/my-gpt`；加 `--resume` 续训，`--generate-only` 只生成。
- 实验室允许修改模型和训练参数、查看曲线、验证损失和生成文本；最近五次验证结果保存在浏览器中用于比较。
- 修改当前或依赖代码后需要重测。末尾“下一任务”只在当前版本通过后出现。

## 数学约定

新课程 Linear 的 W 为（输入特征数 C，输出特征数 D），前向为 XW+b。

旧项目 `src/minigpt/nn.py` 的 W 为（D,C），前向为 XWᵀ。旧项目未被修改；两套存储方向不能混用代码。

## 分层验收与理解展示

- Linear 页面在“样例与演算”内展示矩阵梯度显微镜：选择 batch/token/特征，切换 Y、dX、dW、db，逐项或自动累加；dW 显示所有 batch/token 对共享权重的贡献。
- AttentionCore 展示全部 batch/head 的概率图。前向按 query 行看读取，dV 按 value/key 列看所有 query 的贡献；还可切换 Softmax 耦合梯度与 Q/K 两路梯度。
- Block 展示第二条残差与第一条残差的直连/子网络两路梯度及相加结果，与当前公开样例一致。
- 测评标明分类，失败时显示具体输出/梯度路径、形状或首个错误坐标。差分验收检查每个参数张量的固定随机选点，配置、样例和判断方式公开；其误差理论仍在拓展。
- 第九部分末尾新增 miniGPT 项目综合验收，汇总八个阶段的当前完成状态，独立检查训练入口、梯度、因果性、共享权重、过拟合、评估状态、生成与恢复。
- 测评标准或前置代码更新时，旧记录保留并提示重测。单独通过综合任务不自动把所有前置练习标为通过。
- `scripts/strengthen_assessments.py` 由后续课程构建自动调用，生成分层测评、分步练习与残差展示数据；重复运行不累计重复用例，不覆盖个人练习。
- `webapp/understanding.js` 承载交互演算；`exercises/_assessment.py` 承载独立行为/梯度检查和错误坐标诊断。

## 独立实现与拓展（2026-11-07）

- 主线末尾加入独立 Linear、独立 Block、独立 GPT。只给方法接口，构造函数也留空；最终 GPT 含新词表/宽度/头数/批次/序列长度的迁移用例和完整综合验收。最终独立任务同样提供个人模型实验室。
- 错误修复只放在“拓展 · 典型错误修复”：偏置归约、head 换轴、残差直连、共享词表梯度、训练清零。它们不计入主线进度、不进入主线下一任务、不作为主线依赖。
- 每页有折叠的完整模型地图，支持修改尺寸、切换前向/反向、点击节点查看参数/缓存/形状并跳转章节。整数 token 编号明确不求导。
- Linear、AttentionCore、Block、GPT 等页加入独立保存的理解检查。先判断，再展开演算；理解进度不代替代码测评。
- Linear、AttentionCore、Block 的失败项可跳转到梯度展示。数值用例使用该用例输入；行为/差分检查明确提示先用固定样例定位路径。二维/四维 Linear 用例引导至展平与恢复章节，避免冒充三维数据。
- 实验室可提供单独验证文本，不使用验证集扩展训练词表；留空按字符前80%/后20%划分。训练/验证各取至多16个固定均匀窗口作趋势比较。
- 每次记录包含源码快照、配置、文本、划分、源码/数据/实验器 SHA-256 和 Python/NumPy 版本；历史回放使用快照，不覆盖当前草稿。支持导出/导入 JSON，导入仅供查看，点击回放才执行快照。
- 实验诊断包括固定窗口训练/验证交叉熵、每步随机批次损失、裁剪前梯度范数、相对更新幅度、每个 Block 和最终 RMSNorm 输出 RMS。最近五次实验保存在当前浏览器。
- 本地使用独立 GPT：`python exercises/run_gpt.py corpus.txt --independent --steps 100`。检查点记录模型来源，续训/只生成时沿用来源。
- 构建链末尾新增 `scripts/build_independence.py`，仍不会覆盖任何已有个人练习。

索引练习使用 solve(X,ids,k)，样例明确显示 k；演示依次复制行、标出 [0,k) 并截取列。已有旧草稿需手动将入口增加 k，个人函数体保留。
